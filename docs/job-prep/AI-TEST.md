# 🤖 AI 활용 테스트 대비 트랙

> **왜 이 트랙:** 2025~2026 기술면접이 "코드를 짤 수 있나" → **"AI를 잘 몰고·검증하고·선택을 방어하나"** 로 이동.
> **너의 우위(반드시 각인):** 넌 이걸 이미 시스템으로 만든 사람이다 — AI 하네스(스킬 59·에이전트 17·검증 게이트·서브에이전트 오케스트레이션·falsification-first 검증). 남들은 "AI 써봤어요", 넌 **"AI 실패모드를 코드 게이트로 막는 인프라를 설계·운영했어요."** 이 트랙의 목표는 그 경험을 면접 언어로 번역하는 것.

### 🖥️ Meta형 라운드 해부 (가장 흔한 실전 포맷)
```
┌─────────────┬──────────────────┬──────────────┐
│ 파일 탐색기  │   코드 에디터     │  AI 챗 패널   │
│ (멀티파일   │   (네가 편집)     │ (AI는 답만·  │
│  코드베이스) │                  │  파일편집 X) │
└─────────────┴──────────────────┴──────────────┘
    60분 · 3단계 진행:
    ① 🐛 버그픽스  →  ② 🔨 코어 구현  →  ③ ⚡ 최적화
```
**핵심:** AI는 챗으로 조언만 하고 **파일을 직접 못 고침** → 네가 **판단·통합·검증**의 주체. "AI가 대신 풀어주는 시험"이 절대 아니라 **"AI를 도구로 쓰는 너의 판단력"** 시험.

## 🎯 4대 역량 (드릴 대상)

### 1. 🎯 프롬프팅 / 컨텍스트 설계
- 멀티파일 코드베이스에서 **관련 맥락만 골라 AI에 주입** (전체 덤프 X)
- 큰 작업을 **검증가능한 작은 단위로 분해**해서 요청
- 하네스 연결: 네 JIT 검색(전체 331K→800토큰)·서브에이전트 태스크 분해가 곧 이 역량
- 🏋️ 드릴: 낯선 오픈소스 파일 1개 → "이 버그 고쳐줘"를 **맥락 3줄 + 제약 명시**로 프롬프팅. 나쁜 프롬프트 vs 좋은 프롬프트 대조.

### 2. 🔍 검증 · 회의(skepticism) — **가장 중요**
- AI 출력을 **믿지 말고 반증우선으로 읽기** (환각·엣지케이스·미묘한 버그)
- "이거 왜 맞다고 확신해?"에 답할 근거 확보
- 하네스 연결: `verifier-falsification-first`(agreement bias 회피, failure detection +25%p), 검증 게이트, 3-오라클 대조
- 🏋️ 드릴: AI가 짠 코드에 **일부러 심어둔 버그**를 제한시간 내 찾기. "그럴듯하지만 틀린" 답 감별 연습.

### 3. ⚖️ 툴 / 접근 선택 방어
- "왜 이 라이브러리? 왜 이 구조? AI 제안을 **왜 거절/수용**?"
- AI가 준 3가지 옵션에서 **트레이드오프로 하나 고르고 방어**
- 🏋️ 드릴: AI에 "3가지 방법 줘" → 각각 트레이드오프 표 만들고 **하나 선택 + 이유**. 아키텍처 4틀 재활용.

### 4. 🗣️ 의사결정 서사화 (take-home 방어)
- 과제 후 "왜 그렇게 했나" 방어: [상황→결정→트레이드오프→**mitigation**] 4틀
- "AI가 제안했지만 **내가 이래서 바꿨다**"가 시니어 신호
- 🏋️ 드릴: 작은 기능을 AI로 구현 → **결정 로그**(무엇을 AI에 맡기고/거절/검증했는지) 작성 → 5분 구두 방어.

## 🗡️ 너의 하네스 → 면접 스토리 매핑

> 이미 만든 걸 면접 언어로. 각 항목 = "AI 협업 STAR 스토리" 후보.

| 하네스 자산 | 면접에서 증명하는 역량 |
|------------|----------------------|
| verifier-falsification-first | "AI 출력을 맹신 안 하고 검증 프로토콜을 설계" |
| 검증 게이트(gate-1·ship-radar·preflight) | "AI가 저지르는 회귀를 코드 게이트로 left-shift" |
| 서브에이전트 오케스트레이션 | "큰 작업을 병렬 검증가능 단위로 분해" |
| 박제 메모리(auto-PR 지식그래프) | "AI 협업 지식을 팀 자산으로 복리 축적" |
| JIT 검색(99.8% 토큰절감) | "컨텍스트를 효율적으로 주입하는 설계" |

**엘리베이터 피치(연습):** *"저는 AI를 '빠른 코드 생성기'가 아니라 '검증 가능한 협업자'로 다룹니다. PR 리뷰 게이트도 없는 실상용 앱에 에이전트를 태우면서, AI가 저지르는 실패를 박제·측정·차단하는 자기개선형 하네스를 3.5개월 운영했습니다. 그래서 저는 AI를 언제 믿고 언제 의심해야 하는지를 코드 레벨로 압니다."*
