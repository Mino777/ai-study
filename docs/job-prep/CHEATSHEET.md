```

  비트맵 = 해상도 × 4bytes(RGBA)  ← 파일 용량과 무관!
  1080×1080 = 4.5MB (JPEG 300KB든 2MB든 동일)
  → 디스크=압축(1000장) / 메모리=디코딩(20장) = 200배 차이
  → 상한은 장수 ❌ 총 바이트(cost) ✅ + 다운샘플링(~100배 절감)

이미지 피드 (최빈출 1위)
  cursor 페이지네이션 (offset = page drift 중복/누락)
  로컬DB SSOT → View는 DB만 관찰 → 온/오프라인 분기 소멸 + 부분 실패 내성
  optimistic + SyncQueue + Idempotency-Key
  충돌: 좋아요=LWW 충분 (CRDT는 오프라인 멀티디바이스 편집용)
  one-way(구조 결정=SSOT) vs two-way(캐시 수치) door
```

## 🔀 축 3.2 — 오프라인·충돌해소 → `sd-b4`

```
⭐ 충돌 발생조건 = 협업 ❌ →  오프라인 × replica≥2  ✅
   (나 혼자 아이폰+아이패드 비행기모드 편집 = 이미 충돌)
   협업이 바꾸는 건 "토폴로지"(WebSocket·presence), 충돌해소는 협업과 무관하게 필요
   놓치기 쉬운 스코핑 축 = 🔥 "유실 허용 여부" (LWW 쓸 자격을 가른다)

편집 단위 잘게 → 자동병합률 ↑, 메타데이터·복잡도 ↑
  문서전체(LWW/fork, 단순) < 블록(LWW+순서키, ⭐스위트스팟) < 문자(OT/RGA, 협업 전용)
  🗝️ 순서 병합이 텍스트 병합보다 어렵다 — index는 CRDT 불가(다른 replica 삽입에 밀림)
      → 정렬키(fractional) + replicaId 타이브레이크

CRDT 3성질: 교환 · 결합 · 멱등 → 순서 무관 수렴 (멱등 = 재전송 안전)
⭐ 수렴 ≠ 유실없음:  LWW-Register도 CRDT (버리며 수렴) / OR-Set·RGA (보존하며 수렴)
tombstone: 진짜 삭제하면 다른 replica가 🧟 부활시킴 → deletedAt 마킹 + GC는 전원 확인 후
⭐ 기기 wall clock 불신(유저가 바꿈·drift) → Lamport / HLC + replicaId
서버 = 진실 ❌ 전달자(relay) ✅  ← B2와 역전되는 지점
ID를 클라가 발급(UUID) — 오프라인 생성에 서버 ID 대기 불가
one-way door: 편집 단위 + ID 발급 주체 / two-way: sync 주기·배칭·debounce
```

## 🗺️ 축 3.4 — 지도 심층 → `sd-m1-map-deep`

```
3층으로 말한다: 좌표·타일 / 공간쿼리·집계 / 렌더·스트리밍  (병목이 층마다 다름)

L0 좌표:  WGS84(lat/lon) vs Web Mercator(평면m) · 왜곡배율 = 1/cos(위도) (서울 1.26)
          ⭐ GeoJSON 순서 = [경도, 위도] — 사람 말 순서와 반대. 뒤집으면 조용히 판정 false
L1 타일:  m/px = 156,543 / 2^z × cos(φ) · 타일수 4^z · 화면당 6~12장(20~50KB)
          → z≤12 개별마커 무의미(겹침) / z≥15 의미있음  = 클러스터 경계의 *근거*
L2 인덱스: geohash(prefix 쉬움·⚠️경계누락→이웃9셀) / quadtree(타일과 격자 일치=캐시최강)
          / S2(구면·Hilbert) / H3(육각·⭐6이웃 등거리, 집계용)
          ⭐ DB에 공간인덱스 있으면 직접 격자 설계 안 한다
L3 쿼리:  5단방어 = debounce(300~500ms·leading) → 격자스냅(캐시키) → 포함스킵
          → 마진 20~30% → ⭐최신 요청만(gen 번호, 오래된 응답 폐기)
L4 클러스터: 하이브리드(낮은줌=서버집계 / 높은줌=클라). 경계는 ⭐서버 설정값
          안정성 4수: 셀중심 고정 · 라벨 숫자만 갱신 · 히스테리시스 · 애니메이션 억제
L5 렌더:  16.6ms 예산 · ⛔전체 remove/add · ✅ diff(add/remove/좌표만)
          아이콘 사전렌더 캐시 · 재사용 풀 · ⭐개별마커 상한 필수
          마커 한계 넘으면 → 타일 오버레이/배치 드로잉으로 내려간다
L6 실시간: 폴링(시작) → 적응폴링 → WS 뷰포트구독 → 델타압축. 백그라운드 = 구독해제
L7 GPS 3거짓말: 정확도편차 · 점프(멀티패스) · 오래된 fix
          필터: accuracy → 신선도 → ⭐속도 타당성(불가능 속도=이상치) → 스무딩
          ⭐ 저장은 원본, 표시는 가공 (스무딩 저장하면 요금 근거 훼손)
L8 거리:  목록 정렬=직선(haversine/근사) · 상세 1건만 도로거리 API (⛔목록마다 호출)
L9 권한:  거부를 정상경로로. iOS14+ ⭐근사 위치 가정 · 화면을 근사/정밀 2등급 분리
L10 배터리: 정확도 하향 · 주기 적응 · ⭐백그라운드 전면중단 · wake 횟수가 바이트보다 비쌈
L11 오프라인 지도: 기술보다 ⚠️라이선스(타일 캐시 허용?) 먼저. 전국 사전다운 ⛔

🔬 실무 대조: ⭐내 지도 문제 = 클러스터링 아니라 "2단 폴리곤 구역판정"
   가능 = point ∈ activeGeom  AND  point ∉ inactiveGeom  (도넛/구멍)
   클라=즉각 피드백(UX) / 서버=최종 진실  ← 요금과 같은 원칙
   자기 코드 갭: 위치 start 13곳 : stop 1곳 + 전역 최고정확도 (실측은 미완)
                지도 Provider 1,800줄 God object 3벌 복제
                → "지금이라면 구역판정을 SDK 비의존 순수함수로 먼저 떼어낸다"
```

## 💳 축 3.5 — 결제 심층 → `sd-m2-payment-deep`

```
⭐ L0 exactly-once는 불가능 (도착했는데 응답유실 vs 도착실패를 구별 못 함)
   → at-least-once 전달 + 멱등 처리 = "효과적 exactly-once"
멱등키: 같은키 재요청→첫결과 반환 / 같은키+다른페이로드→에러 / 유효기간 존재
   클라: 키는 "시도 1건"에 귀속·로컬DB 저장 · 재시도엔 ⭐같은 키 · 유저가 다시결제=새 키
   ⛔최다버그: 재시도마다 새 UUID → 멱등성 무효 (불안정 네트워크에서만 재현)
   서버 최종방어 = ⭐멱등키 UNIQUE INDEX (앱 로직만으론 경합에서 뚫림)

상태머신: draft→held(+TTL⭐)→paying→paid→active→completed
   ⭐ ambiguous(모르는 상태)를 명시적 상태로 둔다 · 상태는 디스크에 · 전이 권한은 서버만
4중방어: UI락(실수탭) / 멱등키(재시도) / 상태머신(다른세션) / ⭐reconcile(앱종료)
   reconcile: 요청 "직전에" 로컬기록 → 포그라운드마다 GET 조회 → ⛔임의 재결제 금지

⭐ 실패 3분류: retryable(타임아웃·5xx→백오프) / terminal(카드거절→즉시안내)
              / ambiguous(응답없음 → ⛔재시도 ✅조회)  ← 이중결제 최대 원인
   에러코드+retryable 플래그를 서버가 내려준다 (문자열 분기 ⛔)

⭐ hold→capture 2단 (카셰어링 핵심): 예약시 예상금액 승인 → 반납후 실사용 매입
   실사용<예상 → 부분매입 / >예상 → 추가결제 or 미납 / 취소 → 전액 해제
   난제: hold 유효기간 < 장기대여 · 추가결제 실패 → 미납채권 · 환불도 멱등키 필요

⭐ 웹뷰 결제(내 실무): 왜 = PG/결제수단 파편화를 웹1벌 + 정책 변경 즉시배포(앱=비가역)
   대가 = 앱 생명주기↔웹상태 불일치 · 콜백유실 · 외부앱 왕복 · 세션브릿지 · 디버깅 분산
   네이티브 5책임: 세션브릿지 · 디바이스기능(카드OCR) · 외부앱 전환/복귀 · ⭐복귀시 reconcile · 관측
   ⭐ 콜백은 빠른 경로일 뿐, 진실은 서버 조회. 3중 = 콜백 + webhook + 폴링
순차 자격게이트: 로그인→본인인증→면허→결제수단→미납없음→예약가능 (게이트 정의는 서버)
```

```
❌ await는 블로킹              → ✅ 양보(suspend)

❌ CRDT면 유실 없다            → ✅ 수렴 ≠ 유실없음 (LWW도 CRDT, 버리며 수렴)

❌ 타임아웃이니 재시도          → ✅ 모호(ambiguous)는 조회 (재시도 = 이중결제)
❌ 멱등키만 있으면 이중결제 끝   → ✅ 재시도 경로만 막음. 상태머신 + DB UNIQUE 필요
❌ GeoJSON은 [위도, 경도]      → ✅ [경도, 위도] (뒤집으면 에러 0건, 판정만 false)
```
