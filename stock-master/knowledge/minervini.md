# 마크 미너비니 — SEPA / Trend Template / VCP

> US Investing Championship 2회 우승. 1990년대 연평균 220% 수익 (최대 낙폭 제한적).
> 핵심: **"성장주를, 추세가 확인된 후, 변동성이 수축한 지점에서, 좁은 손절로 산다."**

---

## 1. SEPA (Specific Entry Point Analysis)

5개 축이 **동시에** 정렬돼야 매수 후보다.

| 축 | 내용 |
|----|------|
| **Trend** | 추세가 이미 상승 중 (선행 아닌 확인 후 진입) |
| **Fundamentals** | 매출·이익 가속. EPS 성장률이 **분기마다 빨라지는지** |
| **Catalyst** | 신제품·실적서프라이즈·산업 사이클 등 촉매 |
| **Entry Point** | VCP 등 저위험 진입 지점 (피벗) |
| **Exit Plan** | 진입 **전에** 손절가 확정 |

### 핵심 사상
- **"주가는 이미 오른 종목이 더 오른다"** — 신고가 근처를 두려워하지 않는다.
- 바닥 잡기(bottom fishing) 금지. 하락 추세 종목은 아무리 싸도 후보 아님.
- 저PER이 매수 근거가 아니다. 미너비니는 **성장 + 추세**를 산다.

## 2. Trend Template — 8개 조건 (필터, 하나라도 실패 시 탈락)

```
1. 현재가 > 150일선 AND 현재가 > 200일선
2. 150일선 > 200일선
3. 200일선이 최소 1개월(이상적으로 4~5개월) 상승 중
4. 50일선 > 150일선 AND 50일선 > 200일선
5. 현재가 > 50일선
6. 현재가가 52주 신저가 대비 최소 +30% 위     ← (일부 자료 25%, 원전은 30%)
7. 현재가가 52주 신고가 대비 -25% 이내 (신고가에 가까울수록 좋음)
8. RS(상대강도) 랭킹 70 이상 — 이상적으로 80~90+
```

### 실전 해석
- **1~5번 = 정배열 확인.** 50 > 150 > 200 순서로 쌓이고 주가가 그 위.
- **6번**은 "바닥에서 이미 탈출했다"는 증거. 바닥 근처면 아직 아니다.
- **7번**이 핵심 반전 포인트 — 대부분 개인은 신고가를 무서워하는데, 미너비니는 **신고가 -25% 이내**를 요구한다.
- **8번 RS**: 시장 대비 상대강도. 한국은 RS 랭킹 제공이 제한적 → **코스피 대비 상대수익률**로 대체 계산.

> 📌 **한국 시장 적용 시**: 미국은 IBD RS Rating이 있지만 한국은 없다.
> 대안 → `(종목 6개월 수익률) - (코스피 6개월 수익률)` 로 상대강도 자체 산출, 상위 20~30% 선별.

## 3. VCP (Volatility Contraction Pattern)

### 정의
상승 후 조정 과정에서 **조정 폭이 단계적으로 줄어들고, 거래량도 함께 마르는** 패턴.
공급(매도 물량)이 소진됐다는 증거 → 적은 매수세로도 돌파 가능.

### 구조
```
1차 조정: -25%  거래량 大
2차 조정: -12%  거래량 中     ← 조정폭이 대략 절반씩 축소
3차 조정:  -6%  거래량 小
        ↓
    피벗 포인트 (돌파 지점) → 거래량 급증하며 돌파
```

### 판정 기준
| 항목 | 기준 |
|------|------|
| 수축 횟수 | **2~6회** (T=2~6). 보통 3~4회 |
| 수축 비율 | 각 조정폭이 직전의 **약 50%** 수준으로 축소 |
| 거래량 | 수축마다 **감소**. 마지막 구간은 거래 고갈(dry-up) |
| 기간 | 수 주 ~ 수 개월 (베이스 형성 기간) |
| 돌파 | 피벗 돌파 시 **거래량 평균 대비 크게 증가** 필수 |

### ⚠️ 가짜 VCP 판별
- 거래량이 **안 줄어들면** VCP 아니다 → 그냥 하락 조정
- 조정폭이 **커지면** VCP 아니다 → 추세 붕괴 신호
- 돌파할 때 **거래량 안 터지면** 가짜 돌파(fakeout) 위험 ↑

## 4. 리스크 관리 규칙

| 규칙 | 수치 |
|------|------|
| **최대 손절** | -7~8% (절대 넘기지 않음) |
| 계좌당 리스크 | 거래당 자본의 **1.25~2.5%** |
| 손익비 목표 | 최소 **2:1**, 이상적으로 3:1 이상 |
| 승률 전제 | 50% 내외여도 손익비로 이긴다 |

### 손절이 먼저다
> "매수 버튼 누르기 전에 손절가를 안 정했으면, 그건 투자가 아니라 도박이다."

- 손절폭이 8%를 넘어야 하는 자리 = **애초에 진입하면 안 되는 자리**
- 피벗 바로 위에서 사야 손절이 좁아진다. 이미 20% 뛴 뒤 추격 = 손절폭 폭발

### 피라미딩 (불타기) — 물타기 절대 금지
```
1차 진입: 목표 포지션의 50%  (피벗 돌파 시)
2차 추가: 25%  (+2~3% 상승 확인 후)
3차 추가: 25%  (추가 상승 확인 후)
```
**이기는 포지션에만 더한다.** 지는 포지션에 추가 = 계좌 파괴의 지름길.

## 5. 매도 규칙

### 손절 (기계적)
- -7~8% 도달 → **무조건** 청산. 예외 없음.
- 돌파 후 피벗 아래로 되밀리면 조기 청산 고려

### 익절 (재량)
- 상승 중 **거래량 폭발 + 급등(climax run)** → 분할 익절
- 50일선 이탈 → 추세 훼손, 축소 또는 청산
- 손익비 3:1 도달 시 일부 실현 후 나머지는 추세 추종

## 6. 시장 국면 (Market Timing)

미너비니는 개별 종목만 보지 않는다. **시장 전체가 하락 추세면 현금 비중을 올린다.**

| 국면 | 신호 | 대응 |
|------|------|------|
| 상승 확인 | 지수 정배열, 신고가 종목 다수, 돌파 성공률↑ | 풀 포지션 |
| 경고 | 돌파 실패 증가, 분산일(distribution day) 누적 | 신규 진입 축소 |
| 하락 | 지수 200일선 이탈, 주도주 붕괴 | **현금**. 역추세 매수 금지 |

> **분산일(Distribution Day)**: 지수가 거래량 증가와 함께 하락한 날.
> 4~5주 내 5회 이상 누적되면 조정 경고.

## 7. 한국 시장 적용 체크리스트

```
□ 정배열인가? (5 > 20 > 60 > 120일선)
□ 60일선/120일선 위에 있나?
□ 52주 신고가 대비 -25% 이내인가?
□ 코스피 대비 상대수익률 상위권인가?
□ 최근 조정에서 거래량이 말랐나? (VCP)
□ 실적이 가속 중인가? (분기 YoY 증가율 상승)
□ 손절폭 8% 안에 들어오는 자리인가?
□ 지금 시장 국면이 신규 진입 허용 구간인가?
```

**8개 중 하나라도 ❌면 관망.** 미너비니의 강점은 진입 종목 수가 아니라 **거른 종목 수**다.
