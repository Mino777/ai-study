# 리스크 관리 & 매매 심리

> **이 문서가 지식베이스에서 가장 중요하다.**
> 진입 기법은 대체 가능하지만, 사이징과 손절 규율은 대체 불가능하다.

---

## 1. 1R 개념 (Van Tharp)

```
R = 해당 트레이드의 초기 리스크 = (진입가 − 손절가) × 수량
```

모든 손익을 **R 배수**로 기록한다. +2R, −1R, +5R…

### 왜 필수인가
3,000만 원 넣어 30만 원 번 것과 500만 원 넣어 30만 원 번 것은 **완전히 다른 트레이드**다.
금액·수익률(%)로는 비교 불가. **R로 환산해야만** 서로 다른 종목·시점·변동성을 동일 척도로 비교할 수 있다.

- 시스템의 정의 = **R 배수의 확률 분포**
- **규칙: 손절은 항상 −1R을 넘지 않는다.**
  −2R, −3R이 기록에 나타나면 **전략 실패가 아니라 규율 실패**다.

## 2. Fixed Fractional — 실전 표준

```
리스크 금액 = 계좌 총자산 × r        (r = 1~2%)
매수 수량   = 리스크 금액 ÷ (진입가 − 손절가)
```

### 계산 예시
```
계좌 5,000만, r=1% → 리스크 50만
진입 20,000 / 손절 19,000 → 주당 리스크 1,000원
수량 = 500,000 ÷ 1,000 = 500주 (투입 1,000만 = 계좌의 20%)
```
손절폭이 2.5%(19,500원)면 → 주당 500원 → **1,000주** (투입 2,000만 = 계좌의 40%)

> ★ **핵심: 투입 금액이 아니라 리스크 금액이 일정하다.**
> 손절폭이 좁으면 크게, 넓으면 작게 산다. 이것이 변동성 정규화.

### r 값 선택
| r | 성격 | 20연패 시 |
|---|------|-----------|
| 0.5% | 매우 보수적, 검증 중 전략 | −9.5% |
| **1%** | **표준 권장** | −18.2% |
| 2% | 공격적, 검증된 전략만 | −33.2% |
| 5% | ☠️ 파산 위험 | −64.2% |

⚠️ **20연패는 승률 60% 전략에서도 장기적으로 거의 확실히 발생한다.**
r=5%면 그 한 구간에서 계좌가 사실상 회복 불가능.

**총 포트폴리오 리스크 상한**: 개별 1%씩 5종목이라도 시장 급락 시 상관관계가 1에 수렴.
→ **총 리스크 ≤ 6%** 를 별도 한도로 둔다.

## 3. 켈리 공식 — 쓰는 법이 따로 있다

```
f* = (bp − q) / b = p − (1−p)/b

b = 손익비, p = 승률, q = 1−p
```

### 계산 예시
| 승률 | 손익비 | f* |
|------|--------|-----|
| 45% | 2.0 | **17.5%** |
| 60% | 1.0 | 20% |
| 40% | 1.2 | **0 → 진입 금지** |

### ⚠️ 켈리를 그대로 쓰면 안 되는 3가지 이유
1. **f*는 기하평균 수익 최대화이지 위험조정수익 최대화가 아니다.** Full Kelly는 **50%+ 드로다운이 통계적으로 필연**
2. **입력값이 추정치다.** p를 5%p만 과대추정해도 f*가 크게 튄다. **f* 초과 베팅은 성장률이 음수** (over-betting은 비대칭적으로 파괴적)
3. **주식은 이진 결과가 아니다.** 갭하락·하한가로 손실이 −1R을 넘는다 → 켈리의 전제가 깨짐

### Half Kelly
성장률의 **약 75%를 유지하면서 변동성은 절반**. 이 비대칭(성장 −25% / 리스크 −50%)이 표준인 이유.
퀀트 실무 관행: **1/4 ~ 1/2 Kelly**.

### ★ 실전 통합 권고
> **켈리는 사이즈를 정하는 도구가 아니라, 내 전략에 엣지가 실재하는지 검증하는 도구다.**
> - `f* ≤ 0` → 엣지 없음. **매매하지 마라**
> - `f* > 0` → 엣지 확인. 실제 베팅은 **Fixed Fractional 1~2%**
> - f*=17.5%인데 r=1%면 = 1/17.5 Kelly. 추정오차에 대해 충분히 안전.

## 4. 기대값 — 승률은 단독으로 무의미하다

```
E = (승률 × 평균이익R) − (패율 × 평균손실R)
평균손실 1R 정규화 시:  E = p × b − (1 − p)
```

| 승률 | 손익비 | 기대값 |
|------|--------|--------|
| **40%** | 2.5 | **+0.4R** |
| 60% | 1.0 | +0.2R |
| 70% | 0.5 | +0.05R |

> 🚨 **승률 40%짜리가 승률 70%짜리보다 트레이드당 8배 번다.**

### 손익분기 승률
```
손익분기 승률 = 1 / (1 + R)
```
| 손익비 | 손익분기 승률 | 실질 필요승률* |
|--------|--------------|---------------|
| 0.5:1 | 66.7% | ~68.5% |
| **1:1** | **50.0%** | ~51.5% |
| 1.5:1 | 40.0% | ~41.2% |
| **2:1** | **33.3%** | ~34.3% |
| **3:1** | **25.0%** | ~25.8% |
| 4:1 | 20.0% | ~20.7% |
| 5:1 | 16.7% | ~17.3% |

\* 왕복 비용 약 0.2~0.25%(거래세 0.15% + 수수료 + 슬리피지)를 손절폭 3% 기준 환산한 근사치.
→ **손절폭이 좁을수록 비용 비중이 커진다. 스캘핑에서 손익비 1:1이 실질 마이너스 게임인 이유.**

### 눌림목 매매에의 함의
1. **눌림목의 구조적 강점은 승률이 아니라 손익비다.** 지지선 바로 위 진입 → 손절폭 3~5%. 목표는 전고점 돌파 → 10~20%. **구조 자체가 R=2~4**
2. **손익비 2 미만 자리는 진입 안 한다.** `(목표−진입) ÷ (진입−손절) ≥ 2` 계산 후 진입. 위에 두꺼운 매물대로 목표가 낮으면 → **스킵**
3. **총 기대값 = 기대값(R) × 횟수 × 1R.** 횟수를 늘리면 셋업 품질이 떨어져 기대값이 같이 하락 → **횟수보다 기대값을 올려라**
4. **표본**: 최소 30회, 신뢰하려면 **100회 이상**. 10회로 계산한 승률 70%는 통계적으로 무의미.

## 5. MDD와 회복의 비대칭 ★

```
필요 회복 수익률 = D / (1 − D)
```
**모델이 아니라 산술 항등식이다.**

| MDD | 필요 회복 | 배율 |
|-----|-----------|------|
| 10% | 11.1% | 1.11× |
| **20%** | **25.0%** | 1.25× |
| **30%** | **42.9%** | 1.43× |
| 40% | 66.7% | 1.67× |
| **50%** | **100%** | **2.00×** |
| 70% | 233% | 3.33× |
| **75%** | **300%** | **4.00×** |
| 90% | 900% | 10.0× |

### 왜 비대칭인가
분모가 다르다. 1억 → −25% → 7,500만. 회복하려면 7,500만이 2,500만을 벌어야 → **33.3%**.
손실은 큰 금액의 25%, 회복은 작은 금액의 33.3%.

### ★ 실전 함의
1. **비선형 임계점 = 20~30%.** 여기까진 1.25~1.43배로 따라잡을 수 있다. **30% 넘으면 급격히 발산**
   → **MDD 20% 도달 시 사이즈 절반, 30% 도달 시 전면 중단 후 재검토**
2. **−1R 손절을 지키는 진짜 이유**: r=1%로 20연패해도 MDD 18.2%, 회복 22.3% → 복구 가능.
   반면 **손절 한 번을 −10%로 방치하면 3번만에 27%가 날아간다**
3. 연패별 잔고 `(1−r)^n`
   | r | 10연패 | 20연패 |
   |---|--------|--------|
   | 1% | −9.6% | −18.2% |
   | 2% | −18.3% | −33.2% |
   | 3% | −26.3% | **−45.6%** |
   | 5% | −40.1% | **−64.2%** |

   r=3%부터 20연패가 회복 난이도 임계를 넘는다. **r=1~2% 권장의 정량 근거.**
4. **MDD는 심리적 파산 지점이기도 하다.** 수학적으로 회복 가능해도, 40% 드로다운을 겪은 트레이더 대부분은 규율을 잃고(사이즈 확대·손절 무시) **그 지점에서 실제로 파산**한다.
5. **Recovery Factor = 총수익 ÷ MDD.** **3 이상**이어야 실전 운용 가능.

## 6. 피라미딩 vs 물타기

| | 피라미딩(불타기) | 물타기 |
|---|-----------------|--------|
| 대상 | **수익 중** 포지션에 추가 | **손실 중** 포지션에 추가 |
| 리스크 방향 | 시나리오가 **맞다는 증거**에 추가 | 시나리오가 **틀렸다는 증거**에 추가 |
| 결과 | 최고 종목에 최대 익스포저 | **최악 종목에 최대 익스포저** |

### 왜 피라미딩이 구조적으로 옳은가

**① 리스크 확대 방향이 정반대**
물타기는 손실을 키우고 이익을 제한. 피라미딩은 손실을 제한하고 이익을 키움.
**"Cut losses short, let profits run"과 물타기는 정면 배치.**

**② 물타기는 손절선이 존재할 수 없게 만든다**
평단 낮추기가 목적이므로 손절할 이유가 사라짐 → 손실 상한 −100%.
물타기로 만든 −50% 포지션은 회복에 **+100%** 필요.

**③ 기대값**
하락 추세 종목의 조건부 기대값은 음수(추세는 지속 경향). 음의 기대값에 자금 추가 = 기대값 악화.

**④ 심리**
Livermore: 이기려면 **인간 본성에 반하는 행동**을 해야 한다.
"싸게 사고 싶다" = 본능 = 물타기 / "비싸게 더 산다" = 반본능 = 피라미딩.

> 물타기 심리 경로: 손실 인정 회피 → "투기 아니라 투자다" 합리화 → "손절은 나에게 불필요" → 계좌 붕괴

### 실행법 — 정피라미드 준수
```
❌ 역피라미드: 100주 → 200주 → 400주  (상단 집중 → 평단 급등 → 작은 조정에 손실 전환)
⭕ 정피라미드: 400주 → 200주 → 100주  (아래가 무거움 → 평단 완만 상승)
```

**추가 진입 조건 (전부 충족)**
1. 기존 포지션 **+1R 이상** 수익 중
2. **새로운 기술적 근거** 발생 (전고점 돌파 / 신규 눌림목 완성)
3. 추가분에도 **독립 손절선**, 실행 시 총 손실 −1R 이내
4. 추가 후 전체 손절선을 **본절 이상**으로 상향

**총 리스크 예시**
```
1차: 10,000원 400주, 손절 9,500 → 리스크 20만 (1R)
→ 11,000 도달(+1R). 손절을 10,000(본절)로 상향 → 기존 리스크 0
2차: 11,000원 200주, 손절 10,500 → 추가 리스크 10만
총 리스크 = 10만 (0.5R)
```
> ★ **포지션은 커졌는데 리스크는 줄었다.** 이것이 피라미딩의 본질.

**단점과 반박**: 평단 상승으로 승률은 떨어진다 → 하지만 손익비가 비대칭 개선되어 **기대값은 증가**. 승률 하락은 대가가 아니라 특성.

### 물타기가 정당한 유일한 경우
**사전 계획된 분할 매수(스케일 인)** 일 때만.
진입 전 "10,000/9,500/9,000에 1/3씩, 8,800 전체 손절" 확정 후 실행 = 분할 진입 전략.
> **구분 기준: 손절선이 사전에 정해져 있고 추가 매수 후에도 변하지 않는가.**
> 손절선이 없거나 밀리면 그건 물타기다.

## 7. 매매일지

### 진입 **전** 기록 (사후 기록은 결과 편향으로 오염됨)
| 항목 | 예시 |
|------|------|
| 셋업 유형 | 20일선 눌림 / 전고점 리테스트 |
| 컨플루언스 수 | 20일선 + 전고점 + 거래량감소 = 3개 |
| 진입/손절/목표 | 20,000 / 19,000 / 24,000 |
| **1R 금액 / 손익비** | 50만 / R=4.0 |
| 시장 환경 | 지수 정배열 / 섹터 강세 |
| 진입 심리 (1~5) | 확신 4 / 조급함 2 |

### 청산 후
| 항목 | 목적 |
|------|------|
| 청산 사유 | 목표 / 손절 / 시간손절 / **규율 이탈** |
| **실현 R** | +2.3R / −1.0R |
| **MAE** (최대 역행폭) | 손절선이 타이트/느슨한지 판정 |
| **MFE** (최대 유리폭) | 익절이 너무 이른지 판정 |
| 실행 오류 | 계획 대비 이탈 (Y/N) |

### ★ MAE/MFE — 가장 저평가된 지표
- **승리 트레이드의 MAE 분포**로 최적 손절폭 역산. 이긴 거래들의 MAE가 전부 −1.5% 이내인데 손절을 −5%에 두고 있다면 → **손절을 −2%로 좁혀도 이긴 거래는 하나도 안 잃으면서 진 거래 손실만 60% 감소**
- **MFE vs 실현수익 갭**이 크면 익절이 이르다. MFE 평균 +4R인데 실현 +1.5R → 트레일링 스탑 도입 필요

### 주간/월간 집계
```
승률 · 평균+R · 평균−R · 손익비 · 기대값(R) · 총R · 최대연패 · MDD · Recovery Factor
셋업 유형별 기대값          ← 가장 중요 (어떤 셋업이 실제로 돈이 되는가)
"규율 이탈" 제외 시 기대값   ← 시스템 vs 실행의 분리
```
> ★ 마지막이 결정적이다.
> 규율 이탈 거래 제외 시 기대값이 **크게 개선되면 → 전략은 정상, 문제는 실행(심리)**.
> 제외해도 **음수면 → 전략 자체를 폐기**해야 한다.

표본 기준: 최소 50건, 신뢰 확보는 100건 이상.

## 8. 심리적 오류 8가지

### ① 손실 회피 (Kahneman & Tversky, 1979)
같은 크기 손실을 이익보다 **약 2배 강하게** 느낀다 (λ ≈ 2.25).
→ 손절 확정이 이익 실현보다 2배 고통스러워 회피.
**대응**: 손절을 재량에서 제거. **진입 즉시 역지정가 자동 설정.** 손절을 "결정"이 아니라 **"이미 예약된 사건"**으로 만드는 게 유일하게 작동하는 해법.

### ② 처분 효과 (Shefrin & Statman 1985, Odean 1998) ★
**이익은 너무 빨리 팔고, 손실은 너무 오래 들고 있는 경향.**
- 실증: 투자자는 손실 종목보다 **이익 종목을 약 1.5배 더 자주 매도**. 연 **3~5%p** 수익률 손실
- 🚨 **눌림목 트레이더에게 치명적**: 이 전략의 수익 구조는 "작은 손실 여러 번 + 큰 이익 몇 번"인데, 처분 효과는 정확히 **큰 이익을 잘라내고 작은 손실을 키운다.** **손익비 자체를 뒤집는다.**
- **대응**: 익절도 규칙으로 (1/2 익절 at +2R, 나머지 트레일링). 손절은 자동 실행.

### ③ 확증 편향
매수 후 긍정 정보만 수집. 종목토론방에서 자기 포지션 방향 글만 읽기.
**대응**: 진입 전 일지에 **"이 시나리오가 틀렸음을 증명할 조건"을 문장으로** 명시.
> "20일선 종가 이탈 시 내 판단은 틀린 것이다."
반증 조건을 사전 문서화하면 사후 합리화가 어려워진다.

### ④ 과신 (Barber & Odean, "Trading Is Hazardous to Your Wealth")
연승 후 사이즈 확대 → 한 번의 손실로 전부 반납.
실증: **거래 빈도와 수익률은 음의 상관.**
**대응**: r을 승패와 무관하게 고정. **사이즈는 계좌 자산에 의해서만 변하고 기분에 의해 변하지 않는다.**

### ⑤ 매몰비용 오류
"이미 −30%인데 지금 팔면 손해다" = 논리 오류. 이미 지출된 손실은 미래 의사결정과 무관.
**판정 질문**: *"지금 이 종목을 현금으로 갖고 있다면, 현재가에 신규 매수하겠는가?"* → 아니면 즉시 청산.

### ⑥ 앵커링
자기 매수 단가를 기준으로 삼음. "본전만 오면 판다." **시장은 당신의 매수가를 모른다.**
**대응**: 손절/목표를 매수가가 아니라 **차트 구조(지지·저항)** 로 설정.

### ⑦ 도박사의 오류
3연패 후 "이번엔 이길 차례" → 사이즈 확대. **각 트레이드는 독립 사건.**
역방향도 오류: 3연패 후 "전략이 망가졌다" → 유효 셋업 회피.
**승률 45% 전략에서 3연패 확률 = 0.55³ = 16.6%로 흔한 일.**

### ⑧ 복수 매매 — 가장 파괴적
손절 직후 감정 상태에서 셋업 없이 재진입.
**대응 (구조적 차단)**: **일 손실 −3R 도달 시 당일 매매 종료.** 주간 −6R.
> 이 규칙 하나가 계좌를 지키는 효과는 **어떤 진입 기법보다 크다.**

## 9. 손절 설정법

### ① 구조적 손절 (권장)
손절 = **직전 스윙 저점 아래** 또는 **지지선 −2~3%**
논리: "이 가격을 깨면 내 시나리오 자체가 틀린 것"인 지점. 가장 정당.

### ② ATR 기반 (변동성 적응)
```
ATR(14) = True Range 14일 평균
손절가 = 진입가 − (k × ATR)
```
| k | 용도 |
|---|------|
| 1.5 | 스캘핑, 박스권 |
| **2.0** | **데이/스윙 표준** |
| 3.0 | 중기 추세추종 |

장점: 고변동주는 자동으로 손절폭이 넓어지고 저변동주는 좁아진다 → **노이즈에 털리는 빈도를 구조적으로 감소**.

### ③ 고정 % — 단순하나 종목 변동성 무시
### ④ 시간 손절 (과소평가됨)
진입 후 **3~5일 내 시나리오 미작동 시** 손익 무관 청산.
눌림목은 "빠른 반등"이 전제 → 반등이 없다는 것 자체가 가설 오류 신호.

### 트레일링 스탑
- **5일선 이탈 청산** — 급등 진행 종목, 가장 타이트
- **Chandelier Exit** = `22일 최고가 − (3 × ATR)` — 추세 끝까지
- **본절 이동** — +1R 도달 시 손절을 진입가로. 이후 최대 손실 0. **심리 부담 제거에 가장 실용적**

### 🚫 절대 금지
- **손절선 하향 조정 금지.** 손절선은 **오직 이익 방향으로만** 움직인다. 하향 조정은 물타기의 다른 이름.
- **라운드 넘버 바로 위/아래 금지.** 10,000원은 스탑 사냥 표적 → 9,970원처럼 어긋나게.

## 10. 미노용 리스크 체크리스트

```
【진입 전】
□ 손절가를 정했나? (진입 전에!)
□ 손절폭 8% 이내인가? (미너비니 규칙)
□ 1R 금액이 계좌의 1~2%인가?
□ 손익비 ≥ 2인가?  (목표−진입) ÷ (진입−손절)
□ 역지정가 주문을 걸었나?
□ 반증 조건을 문장으로 썼나?

【포지션 중】
□ +1R 도달 시 본절 이동했나?
□ 추가 매수 = 수익 중일 때만 (물타기 금지)

【계좌 레벨】
□ 총 포트폴리오 리스크 ≤ 6%?
□ 일 손실 −3R 도달? → 당일 종료
□ MDD 20% 도달? → 사이즈 절반
□ MDD 30% 도달? → 전면 중단
```
