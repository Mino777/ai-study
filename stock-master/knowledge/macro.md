## 1. 미국 금리

### 전달 경로
```
연방기금금리(FFR) → 단기금리 → 장기금리·할인율 → 밸류에이션 멀티플 → 자산가격
```
금리는 **할인율**이다. 금리↑ = 미래 현금흐름 현재가치↓ = **성장주(듀레이션 긴 자산) 직격**.
가치주·현금흐름 조기 실현 종목은 상대적 방어.

> ⚠️ **실전 핵심: 레벨이 아니라 방향과 속도.**
> 시장은 이미 반영된 경로(dot plot, Fed Funds Futures 내재확률)와의 **차이(서프라이즈)** 에만 반응한다.

### 장단기 금리차 (10Y − 2Y)
- **정상** = 양(+). **역전** = 음(−) → 시장이 미래 인하(경기둔화)를 예상
- **메커니즘**: 은행은 단기조달·장기대출(만기변환). 역전 시 예대마진 소멸 → 신용공급 위축 → 실물 위축. **자기실현적**

| 항목 | 수치 |
|------|------|
| 1960년대 이후 미국 침체 예측 | **전부 선행** (미스 없음) |
| 역전 → 침체 리드타임 | 6~24개월 (통상 10~22개월) |
| **중앙값** | **약 16개월** |
| **유일한 예외** | **2022~2024 (26개월 최장 역전, 침체 미발생)** |

#### ★ 실전 해석 3원칙
1. **리드타임이 길고 편차 크다** → 역전 즉시 매도는 최악. 역전 후에도 증시는 수개월~1년+ 오르는 경우 흔함
2. **역전보다 "역전 해소(re-steepening)"가 더 위험**. 침체는 통상 곡선이 다시 가팔라질 때(연준 급하게 인하) 시작 → **베어 스티프닝 경계**
3. **2022~24 예외 = 이 지표 무결성이 깨졌다는 증거** (QE로 기간프리미엄 왜곡). 단독 사용 금지 → 신용스프레드·실업률 교차검증

**대안 지표**: 3M-10Y 스프레드(연준 선호), **삼의 법칙**(실업률 3개월 MA가 직전 12개월 최저 대비 +0.5%p 상승 시 침체)

## 2. 달러·환율 → 한국 증시 (4채널)

**DXY 구성**: 유로 57.6% + 엔·파운드·캐나다달러·크로나·프랑. **원화 미포함** ← 괴리의 원인

### ① 환차손 채널
외국인 수익률 = 주가 수익률 **+ 환 수익률**. 원화 약세 시 달러 환산 수익 깎임 → 주가 올라도 손실 → 매도.

### ② 자기강화 악순환 ★ 한국의 핵심 취약점
```
원화 약세 → 외국인 매도 → 매도대금 달러 환전 → 원화 추가 약세 → 매도 가속
```
반대도 성립. **외국인 대량 순매도는 그 자체로 원달러 상승 압력**이다.

### ③ 글로벌 위험선호
DXY 강세 = 리스크오프 = EM 자금유출. 한국은 **MSCI EM 비중 크고 유동성 높아 먼저 팔리는 "ATM 시장"**.
→ 한국 펀더멘털과 **무관하게** 매도당하는 이유.

### ④ 수출 채널 (상쇄)
원화 약세 = 수출기업 원화환산 실적 개선(자동차·조선 수혜).
**단 순효과는 통상 수급(외국인 매도)이 우세.** 반도체는 원자재·장비도 달러결제라 상쇄.

### ★ DXY-원달러 괴리 판독법
DXY는 잠잠한데 원달러만 급등 = **한국 고유 리스크** (외국인 매도 / 유가급등 / 지정학 / 서학개미 달러수요)

```
① DXY 먼저 확인
② 원달러가 DXY보다 더 움직였나?
③ YES → 한국 고유 악재. 코스피에 더 나쁨
   NO  → 글로벌 요인. 상대적으로 덜 우려
```

## 3. 경제지표 — 발표 반응 메커니즘

**대전제: 절대 수치가 아니라 컨센서스 대비 서프라이즈에 반응한다.**

### CPI
- 매월 중순, BLS, 08:30 ET
- **핵심은 헤드라인 아닌 근원(Core)**. 주목: 주거비(가중치 ~1/3, 후행), **슈퍼코어**(주거제외 서비스 = 임금압력)
- 상회 → 인하기대 후퇴 → 금리↑ 달러↑ → 주식↓ (성장주 특히)

### PCE
- 매월 말, BEA. **연준 공식 목표는 Core PCE 2%** (CPI 아님)
- CPI와 차이: 가중치 매월 갱신(대체효과), 제3자 지불 의료비 포함, **통상 PCE < CPI** (연 0.3%p 내외)
- **시장 충격은 CPI가 크고, 정책 판단은 PCE가 결정**

### NFP (고용)
- 매월 **첫째 금요일** 08:30 ET
- 4개 동시 확인: 신규고용 / **실업률** / **시간당 평균임금(임금인플레)** / 참가율 + **과거 2개월 수정치**(최근 수정폭 커짐)

#### ★ 레짐 의존성 — 가장 중요
| 레짐 | 고용 강세의 의미 |
|------|------------------|
| **인플레 우려** | 금리인상/인하지연 → **주식 악재** ("good news is bad news") |
| **침체 우려** | 경기 견조 → **주식 호재** |

**현재 어느 레짐인지 먼저 판단해야 방향을 맞춘다.**

### ISM PMI
- 제조업 = 영업일 1일, 서비스업 = 3일, 10:00 ET
- **기준선 50**. 50선 돌파/이탈 시 반응 최대
- **선행성**: **신규주문** = 미래수요 / **신규주문 − 재고** = 사이클 전환 조기신호 / 가격지불 = 인플레 선행
- **한국 수출과 상관 특히 높음** (글로벌 제조업 사이클 대리지표)

## 4. 유동성

```
순유동성 = 연준 대차대조표(WALCL) − 재무부 일반계정(TGA) − 역레포(RRP)
```

| 구성 | 의미 |
|------|------|
| **WALCL** | 연준 총자산. QE=증가, **QT=감소** |
| **TGA** | 재무부 연준 예금. **증가 = 시장에서 현금 흡수(축소)**. 부채한도 후 국채 대량발행으로 TGA 채울 때가 충격 구간 |
| **RRP** | MMF 등의 연준 하룻밤 예치 = **잠긴 유동성**. 감소 = 시장 유입. **0 근접 시 완충재 소진 → QT가 은행 지준 직접 타격** |

- S&P500과 **약 2~6주 시차 동행** (2020년 이후 레짐)
- ⚠️ 상관이지 인과 아님. 2020년 이후 데이터 과적합 비판 존재. **레벨보다 변화율(추세)로 볼 것**
- 보조: 은행 지급준비금, **SOFR-IORB 스프레드**(자금경색 조기경보)

## 5. 경기 사이클 4국면 & 섹터 로테이션

| 국면 | 특징 | 금리 | 🟢 아웃퍼폼 | 🔴 언더퍼폼 |
|------|------|------|------------|------------|
| **① 회복 (Early)** | 침체탈출, 신용회복, 재고최저 | 완화, 곡선 가파름 | **경기소비재, 금융, 부동산, 산업재, 소재** | 필수소비재, 유틸리티 |
| **② 확장 (Mid)** | **가장 긴 국면**, 이익 양호 | 중립화 | **IT, 커뮤니케이션, 산업재** | (섹터 차별화 최소 구간) |
| **③ 둔화 (Late)** | 성장 정점 후 감속, **인플레↑**, 마진압박 | 긴축, 곡선 평탄/역전 | **에너지, 소재, 필수소비재, 헬스케어, 유틸리티** | IT, 경기소비재 |
| **④ 침체** | 활동위축, 이익감소, 신용경색 | 완화 전환 | **필수소비재, 유틸리티, 헬스케어, 통신** | 산업재, 부동산, IT |

### 실전 원칙
- 국면은 **사후에만 확실**하다 → 확률적 접근
- **Mid 국면은 섹터 로테이션 알파가 가장 작다** → 종목 선택이 더 중요
- **주식은 실물보다 6~9개월 선행.** 침체가 뉴스로 확정될 때 이미 회복 섹터가 오르는 중
- 판단 도구: ISM 방향, 곡선 기울기, 신용스프레드, 실업률 추세, 이익수정비율

## 6. 한국 특수성 ★

### 구조적 사실
- **삼성전자 + SK하이닉스 ≈ 코스피 시총의 약 절반**
- → **코스피 = 사실상 반도체 사이클의 레버리지 상품**
- 한국 수출 **달러 결제 비중 ≈ 83.6%**

### 반도체 사이클 (통상 3~5년)
| 국면 | 특징 | 지표 |
|------|------|------|
| 상승 가속 | 수요↑, 리드타임 장기화, 마진 확대 | DRAM/NAND 현물가↑ |
| **정점** | 사상최대 매출, **공격적 Capex** | Capex 급증 = 하락의 씨앗 |
| 하락 | 재고조정, 마진붕괴, **Capex 삭감** | 재고일수↑, 가동률↓ |
| 저점/회복 | 재고소진, 수주개선 | **Capex 삭감이 바닥 신호** |

#### ★ 핵심 역설
```
Capex 삭감 = 매수 신호
Capex 급증 = 매도 신호
```
감산·투자축소는 12~18개월 뒤 공급부족을, 공격적 증설은 12~18개월 뒤 공급과잉을 만든다.
주가는 실적이 아니라 **공급 사이클을 선행**한다.
→ **적자 국면에서 바닥 잡고, 사상 최대 이익 발표 때 고점** 패턴 반복.

> 📌 **FPER 함정과 직결**: 반도체는 PER 낮을 때가 사이클 고점.
> `knowledge/valuation.md` 시클리컬 역설 참조.

### 수출 지표 — 세계에서 가장 빠른 경기 지표
**매월 1일 전월 실적 전체 공개** (관세청·산업부). 주요국이 한 달 뒤 내는 것과 대비 → 해외 기관도 주시하는 **글로벌 교역 카나리아**.

**3단계 조기 판독**
1. **1~10일 수출** (매월 11일경) — 가장 빠름
2. **1~20일 수출** (매월 21일경) — 확정치 근접
3. 월간 확정 (익월 1일)

**판독 포인트**
- ⚠️ **조업일수 조정 필수** → **일평균 수출액**으로 볼 것. 명절 낀 달은 총액 왜곡
- 품목별: **반도체 증가율이 코스피 방향과 가장 밀접**
- 지역별: 대중국 = 중국경기 / 대미 = 미국수요
- **가격 vs 물량 분해**: 가격 주도면 사이클 후반 가능성

### 무역수지
- **경상흑자 = 구조적 달러공급 = 원화강세 = 외국인 우호**
- **적자 = 원화약세 = 외국인 이탈** → 악순환 발동
- **유가가 결정적**: 에너지 순수입국 → 유가급등 → 수입액↑ → 무역악화 → 원화약세 → **이중 타격**
- ⚠️ **불황형 흑자 주의**: 수출·수입 동반 감소로 나는 흑자는 악재. 흑자 규모가 아니라 **수출·수입 절대 방향** 확인

## 7. 한국 증시 통합 체크리스트

```
【글로벌】
□ ISM 제조업 PMI (특히 신규주문) — 글로벌 제조업 사이클
□ DXY, 미 10년물 — 위험선호
□ 곡선 기울기 (역전? 재가팔라짐?)

【반도체】
□ DRAM/NAND 현물가·고정가
□ HBM 수급
□ 메모리 3사 Capex 가이던스 ← 방향이 핵심

【한국】
□ 1~10일 / 1~20일 일평균 수출 (반도체 증가율)
□ 무역수지 (+ 수출·수입 절대 방향)
□ 원/달러 — DXY 대비 괴리 여부

【수급】
□ 외국인 순매수 누적
□ 프로그램 차익잔고

【심리】
□ VKOSPI (VIX 대비 스프레드)
□ 풋콜 레이시오
```

### 연결 논리 (체인 진단법)
```
글로벌 PMI↑ → 반도체 수요↑ → 한국 수출↑ → 무역흑자↑
→ 원화 강세 → 외국인 순매수 → 코스피 상승
```
**이 체인 중 어디가 끊겼는지 점검하는 것이 한국 증시 분석의 실전 프레임워크.**
