## 1. 거래대금 (미노 핵심 도구)

### 왜 거래대금인가
```
거래량   = 체결 주식 수 (주가에 오염됨)
거래대금 = Σ(체결가 × 체결수량)  ← 종목 간 비교 가능한 유일한 수급 척도
```
1,000원 100만주(10억)와 100,000원 100만주(1,000억)는 같은 "거래량 100만"이지만 **유입 자금 100배 차이**.

### 유효성의 3가지 구조적 근거

**① 유동성 = 슬리피지 상한**
내 주문이 당일 거래대금의 **0.5% 이하**(보수적 0.25%)여야 슬리피지가 무시할 수준.
```
1회 진입 3,000만 → 필요 거래대금 = 3,000만 ÷ 0.005 = 60억 이상
1억 진입          → 200억 이상
```
실전 커트라인: **일 거래대금 300억~1,000억 이상**.
이 아래는 호가 갭이 커서 **지지선을 정확히 맞춰도 체결가가 밀려 손익비가 붕괴**된다.

**② 극단적 쏠림**
2026년 6월 기준 유가증권 상장사 947곳 중 **94%가 일 거래대금 1,000억 미만**.
삼성전자·SK하이닉스 2종목이 전체 거래대금의 **약 절반**.
→ 거래대금 스크리닝 = 모집단을 **2,000개 → 30~50개로 압축**하는 필터.

**③ 주도주 판별 — 잔류일수**
- 주도주 정의적 특성: **거래대금 상위 20위권에 3일 이상 연속 잔류**
- 1일 반짝 = 이벤트성 뉴스 / 연속 잔류 = 지속 유입
- 업종 단위: 같은 업종 **2~3개가 동시에** 반복 등장 → **섹터 로테이션**. 이때 **1등주(거래대금 최상위)** 기대값이 2등주보다 높다

> 📌 **미너비니 연결**: RS 상위 = 결국 돈이 몰리는 종목. 거래대금 상위 스크리닝이 **한국판 RS 필터**.

### 실전 스크리닝 조합
```
거래대금 ≥ 500억
AND 전일 대비 ≥ 200%
AND 등락률 +3% ~ +15%
AND 주가 > 20일선
AND 시총 ≥ 1,000억
```
> 등락률 **상한**을 두는 이유: 상한가 근처는 이미 눌림목 기회가 소멸했고 **다음날 갭 리스크가 비대칭적**으로 크다.

### 거래대금 급증 해석
| 패턴 | 의미 |
|------|------|
| 신고가 + 대금 급증 | **돌파 확인** — 가장 강력 |
| 상승 + 대금 감소 | 매수 소진 / 매도호가 공백. 상단 취약 |
| 하락 + 대금 급증 | **분산(매도)** — 위험 |
| 하락 + 대금 감소 | **건전한 눌림** (VCP 조건) |
| 횡보 + 대금 고갈 | 에너지 응축, 돌파 대기 |

## 1-B. 거래량 지표

### 거래량 비율 (Volume Ratio)
```
VR = 당일 거래량 ÷ 20일 평균 거래량
```
| VR | 해석 |
|----|------|
| < 0.5 | 관심 소멸. **눌림 구간이면 좋은 신호**(물량 안 나옴) |
| 0.8~1.2 | 평상시 |
| 2.0~3.0 | 유의미한 유입. **돌파 신뢰 최소선** |
| ≥ 3.0 | 세력 개입/뉴스. 장대양봉 동반 시 매집봉 후보 |
| ≥ 10.0 | 이상 급증. 고점권이면 **분산(털기)** 의심 우선 |

> ★ **눌림목 전용 규칙**: 눌림 구간 거래량이 **직전 상승 장대양봉의 30% 이하**여야 건강.
> **50% 초과 = 매물이 실제로 나오는 중** → 눌림이 아니라 분산 초기일 확률 급등.

### OBV (On Balance Volume)
```
종가 > 전일 → OBV += 거래량
종가 < 전일 → OBV −= 거래량
```
**절대값 무의미** (시작점이 임의). 방향·기울기·이전 고저점 대비 위치만 본다.

| 용도 | 판정 |
|------|------|
| 추세 확인 | 주가 신고가 + OBV 신고가 → 신뢰 |
| **약세 다이버전스** | 주가 신고가 + OBV 미달 → **매수세 소진, 분산 중** |
| **강세 다이버전스** | 주가 신저가 + OBV 미달 → **매집 중** |

> ★ **눌림목 최고 용법**: 눌림 구간에서 **주가는 밀렸는데 OBV가 안 밀렸으면 물량이 안 나온 것.**
> 주가 횡보 중 **OBV가 먼저 박스 상단 돌파** = 매집 완료 신호.

**⚠️ OBV의 치명적 한계**
- 부호만 붙여 더하므로 **+0.1%와 +10% 상승의 가중치가 같다**. 도지 하나가 거대 거래량을 한 방향에 몰아줌
- 갭 무시
- **보완**: A/D Line — 캔들 내 종가 위치로 가중
  ```
  MFM = [(종가−저가) − (고가−종가)] / (고가−저가)
  A/D += MFM × 거래량
  ```
  윗꼬리 긴 음봉은 MFM ≈ −0.8 → OBV보다 정직하게 분산 포착

### VWAP
```
Typical Price = (고가+저가+종가)/3
VWAP = Σ(TP × 거래량) / Σ거래량
```
당일 09:00부터 누적, 매일 리셋 (Session VWAP).

> ★ **VWAP = 당일 참여자 전체의 평균 매입단가**
> - 주가 > VWAP → 당일 매수자 평균이 **수익 중** → 급락해도 물량 안 나옴 → **지지 강함**
> - 주가 < VWAP → 평균이 **손실 중** → 본전 매도 대기 → **저항 강함**
>
> 이평선은 "가격의 평균"이지만 **VWAP은 "사람들의 손익분기점"** — 이게 우월한 지점.

**눌림목 적용**
1. 시초부터 강한 종목이 VWAP 위에서만 논다 → 추세 유지
2. **VWAP 터치 후 즉시 반등(꼬리)** → 1차 눌림목 매수 자리
3. **VWAP을 종가로 이탈 + 회복 실패** → 당일 추세 종료, 진입 금지
4. **Anchored VWAP**: 급등 시작일·실적 발표일·전고점 형성일에 앵커 → 그 이벤트 이후 전체 참여자 평균단가. **이평선보다 정밀한 지지선 후보**

⚠️ Session VWAP은 누적 평균이라 후행성 큼. **스윙에는 Anchored VWAP을 쓴다.**

## 1-C. 매집 vs 분산

### 매집 4단계
| 단계 | 가격 | 거래량 | 특징 |
|------|------|--------|------|
| 1. 초기 매집 | 저점권 횡보 | 1.5~2배 조용히 증가 | 저점이 조금씩 높아짐 |
| 2. **흔들기** | 급락/가짜 하락 | 급락일 급증 후 **다음날 급감** | 개인 손절 유도. **다음날 거래량이 안 따라오면 실제 매도가 아니다** |
| 3. 물량 잠김 | 좁은 박스 | 극도 감소 | OBV는 상승 유지 |
| 4. 돌파 | 박스 상단 장대양봉 | VR 3배+ | 진짜 시작 |

**핵심 판별**
- **저점 절상 + 거래량 감소** = 팔 사람이 사라졌다는 가장 강한 증거
- **바닥권 윗꼬리 양봉** = 위쪽 악성 매물대를 향해 물량을 받아낸 흔적. **고점권 윗꼬리(분산)와 정반대 의미** → **위치가 의미를 결정한다**
- **OBV 신고가 + 주가 횡보** = 가장 정량적 매집 증거

### 분산 흔적
- 고점권 **대량거래 + 윗꼬리 긴 캔들** (위에서 다 받아준 것)
- 주가 신고가 + **OBV 미갱신** (약세 다이버전스)
- 상승 각도 유지되는데 거래량 계단식 감소
- **거래량 폭증 다음날 시가 갭하락** = 전날 대량거래가 매도였다는 확정 증거
- **회전율 130% 초과 + 급등** = 손바뀜 끝. 신규 매수자가 물량을 다 받음

### 거래량 없는 상승의 위험
매수세가 강해서 오른 게 아니라 **매도 호가가 없어서** 소량 매수에 호가가 밀려 올라간 것.
→ **가격은 올랐는데 그 가격에서 손바뀜이 없었다 = 지지대 미형성.**
→ 매물이 조금만 나와도 **같은 속도로 되돌린다.** 매물대 관점에서 진공(LVN)이라 **하락 시 브레이크가 없다.**

**예외**
- 장기 소외주의 무거래 상승 = 유동성 함정. 진입 자체가 위험
- **강한 상승 3~5일차 거래량 감소는 정상적 "물량 잠김"** 일 수 있음 → **OBV가 안 꺾였는지로 구분**

## 1-D. 갭 & 시초가 거래대금

### 갭 4분류 (Edwards & Magee)
| 종류 | 위치 | 거래량 | 의미 | 대응 |
|------|------|--------|------|------|
| Common | 박스 내부 | 보통 | 무의미 | 무시 |
| **Breakaway** | 박스/매물대 돌파 | **대량 필수** | 새 추세 시작 | **눌림 대기 후 진입** |
| Runaway | 추세 중간 | 중간~대량 | 가속. 전체 상승폭 중간 근사 | 보유 |
| **Exhaustion** | 추세 말단 | **비정상 폭증** | 마지막 불꽃, 반전 임박 | 분할 청산 |

> **구분 규칙**: **Breakaway Gap은 메워지지 않는다.** 갭 하단을 당일 종가로 침범하면 Breakaway가 아니었다고 재분류. **유일한 사후 검증법.**
> **Island Reversal**: 갭업 후 며칠 뒤 갭다운으로 섬 고립 → 최상위 신뢰도 천정 신호.

### 시초가 대량거래 판독
- 동시호가(08:30~09:00) **예상 거래량이 전일 총거래량의 10% 이상**이면 당일 강한 수급 확정. **5% 미만이면 갭이 있어도 힘 없음**
- 시초가 거래대금이 전일 총 거래대금 초과 = **완전한 수급 재편**(신규 세력 진입)

| 갭 상승률 | 실전 |
|-----------|------|
| +1~3% | **눌림목 매매 최적 구간** |
| +3~7% | 갭 메우기 후 지지 확인 |
| +7~15% | **추격 금지.** 첫 눌림 대기 |
| +15%↑ / 상한가 근접 | **진입 금지.** 갭하락 리스크 비대칭 |

> 🚨 **갭상승 시초가 추격매수 금지.** 갭 직후 차익실현이 갭을 메우는 경향이 지배적.
> **갭 후 일시적 조정(=눌림)이 실전 매수 타이밍** — 눌림목 트레이더에게 가장 유리한 구조.

**갭 지지 확인**: 시초 후 **첫 30분 저점이 전일 종가 위** + VWAP이 받쳐주면 갭 유효. **전일 종가 깨면 갭 실패 → 손절.**

## 1-E. 회전율

```
거래량 회전율(%)   = 기간 거래량 ÷ 상장주식수 × 100
거래대금 회전율(%) = 기간 거래대금 ÷ 시가총액 × 100
```
> **유동주식 기준이 더 정확.** 대주주·자사주·정부 지분 제외.
> 오너 지분 60%면 명목 회전율 10%가 실제로는 25%.

| 일 회전율 | 상태 |
|-----------|------|
| < 1% | 소외. 진입 부적합 |
| 1~3% | 정상 관심 |
| **5~10%** | 강한 수급. **단기 주도주 진입** |
| 10~30% | 과열 진행 (급등주) |
| > 30% | 극단 과열 |

**시장 전체 (연환산)**: 50% 중립 / **130%+ 단기 경계(과열)** / 20% 바닥권

### ★ 매매적 의미 — "물량 소화"
- **회전율이 높다 = 매물대가 새로 형성된다.** 급등 구간 회전율 20% = 그 가격대에서 유통물량 20%가 새 주인을 만남. **이 새 주인들의 평단이 다음 눌림의 지지선.**
- **반대 리스크**: 고점 회전율 폭발 = 기존 보유자가 전부 털고 나감.
  **상승 초입 고회전(매집) vs 상승 말단 고회전(분산)은 오직 가격 위치로만 구분된다.**
- **저회전 급등**은 물량이 잠겨 급등도 쉽지만 **하락도 브레이크가 없다.**

## 2. 눌림목 (Pullback)

### 정의
상승 추세 중 발생하는 **일시적 조정**. 차익실현 + 신규 매수 대기 + 세력 물량 조절로 발생.
추세추종의 **가장 좋은 재진입 기회**.

### 유형 1 — 이동평균선 눌림
| 지지선 | 조정 기간 | 조정 폭 | 성격 | 손절 |
|--------|-----------|---------|------|------|
| **5일선** | 1~3일 | 3~7% | 초강세, 급등주 진행형 | 5일선 종가 이탈 |
| 10일선 | 3~5일 | 5~10% | 강세 유지 | 10일선 or 직전 저점 |
| **20일선(생명선)** | 5~15일 | 10~20% | **표준. 승률/손익비 균형 최적** | 20일선 종가 −3% |
| **60일선(수급선)** | 1~2개월 | 20~35% | 중기 마지막 방어선 | 60일선 이탈 = 추세 종료 |
| 120일선 | 3개월+ | 35%+ | **이미 눌림이 아니라 하락 추세** | 🚫 진입 금지 |

> **왜 20일선이 표준인가**: 5일선 눌림은 기회가 짧고 흔들림에 자주 털린다. 60일선까지 오면 이미 추세 훼손 확률이 높다. **20일선 ≈ 1개월 평균단가 = 단기 스윙 참여자 전체의 손익분기점.**

**이격도** `= 주가 ÷ N일 이평 × 100`
- 20일 이격도 **95~100** = 정상 눌림 / **90 이하** = 과대낙폭(추세 훼손 의심) / **110 이상** = 과열, 눌림 대기

### 유형 2 — 전고점 지지 (Breakout Retest) ★ 승률 최고
```
저항선이던 전고점을 대량거래로 돌파
→ 되돌림으로 전고점 재터치
→ 이제 지지선으로 작동 → 반등
```
> **승률이 가장 높은 이유**: 지지선 위치가 이평선처럼 "계산된 값"이 아니라 **실제 매물대가 존재하는 가격**.
> 돌파 전 그 가격에 팔았던 사람들의 재매수 + 돌파 시 매수자의 추가매수가 겹친다.

- **필수 조건**: 돌파 캔들 **VR 2배 이상**. 거래량 없는 돌파의 리테스트는 그냥 **실패한 돌파**
- 진입: 전고점 ±1~2% 밴드 도달 후 **양봉 확인** / 손절: 전고점 −3% 종가 이탈

### 유형 3 — 피보나치 되돌림
```
되돌림 비율 = (고점 − 현재가) / (고점 − 저점)
```
| 레벨 | 성격 |
|------|------|
| 23.6% | 극얕음. 초강세, 대개 눌림 안 잡히고 재상승 |
| **38.2%** | 얕음. 강한 추세. **가장 선호되는 1차 진입** |
| 50.0% | 심리적 반절 (피보나치 수열 아님, Dow 이론 유래) |
| **61.8%** | 깊음. **마지막 방어선. 깨면 추세 무효** |
| 78.6% | 사실상 추세 붕괴. 🚫 진입 금지 |

> 🚨 **피보나치 단독 사용 금지.** **자기실현적 예언**에 의존하므로 다른 근거와 겹칠 때만 의미.
> **컨플루언스 원칙**: 38.2%가 20일선 + 전고점 + HVN과 겹치면 신뢰도가 **지수적으로** 상승.
> → **3개 이상 겹치는 자리만 진입**하는 게 실전 필터.

**앵커 자의성 해결**: 저점 앵커를 **거래량 급증 시작 지점**에 고정하면 자의성이 준다.

### ★★ 진짜 눌림 vs 추세 붕괴 — 정량 판별표

| 항목 | 🟢 진짜 눌림 | 🔴 추세 붕괴 |
|------|-------------|-------------|
| **조정 중 거래량** | 직전 상승봉의 **30% 이하** | 비슷하거나 **증가** |
| **반등 시 거래량** | 다시 **증가** | 계속 감소 (매수 실종) |
| 하락 캔들 | 짧은 몸통, **아래꼬리** | 긴 음봉, **윗꼬리** |
| 이탈 폭 | 지지선 **−3% 이내** 일시, 당일 회복 | −5%+ or **종가 이탈 2일 연속** |
| 되돌림 | **61.8% 이내** | 61.8% 초과 |
| **저점 구조** | 직전 저점 **미갱신 (higher low)** | **직전 저점 하향 이탈 (lower low)** |
| 조정 기간 | 상승 기간의 **1/3~1/2 이내** | 상승 기간보다 길어짐 |
| 이평 배열 | 정배열, **20일선 기울기 상승** | 5일선이 20일선 하향돌파, **20일선 기울기 하향** |
| OBV | 주가만큼 안 밀림 | 동반 하락, 이전 저점 이탈 |
| VWAP | 터치 후 즉시 반등 | 종가 기준 하회 유지 |

### 결정적 단일 기준 3개
1. **거래량 감소 여부** — 눌림의 본질은 "팔 사람이 없어서 밀린 것". **대량거래 동반 하락은 정의상 눌림이 아니다**
2. **저점 절상(Higher Low) 유지** — 다우 이론의 추세 정의 그 자체. **직전 저점을 깨면 상승 추세는 기술적으로 종료**
3. **20일선 기울기** — 가격이 잠깐 이탈해도 20일선이 우상향이면 눌림. **평평해지거나 꺾이면 붕괴**

### ★ 진입 원칙 — "하락 중에 사지 말고, 재상승 확인 후 사라"
떨어지는 칼날을 받으면 지지선을 잘못 잡았을 때 **손절이 무제한 확대**된다.

**진입 트리거 (하나 확인 후 진입)**
- 양봉 캔들 완성 / 전일 고가 돌파 / 5일선 재돌파

> 확인 후 진입은 진입가가 2~3% 불리해지지만 **오진입 빈도가 절반 이하**로 줄어 **총 기대값이 개선**된다.

### 매매 프로세스
```
1. 상승 추세 확인 (정배열 + Trend Template)
2. 조정 진입 → 거래량 감소 확인          ← 최우선 체크
3. 지지선 도달 (컨플루언스 3개 이상)
4. 반등 확인 (양봉/전일고가돌파/5일선재돌파)  ← 확인 후 진입
5. 진입 — 지지선 바로 위
6. 손절 — 지지선 −2~3%
7. +1R 도달 시 본절 이동 → 트레일링
```

### 손절 기준
```
손절가 = 지지선 − (2~3% 여유)
단, 진입가 대비 −8% 초과 시 → 진입 자체를 포기
```
지지선 살짝 이탈 후 되돌리는 **속임수(shakeout)** 가 잦으므로 여유 필요.
단, 8% 이상 줘야 하는 자리면 **나쁜 자리다.**

> 📌 손절 방식 상세(ATR/시간손절/트레일링)는 `knowledge/risk.md` 9장 참조.

## 3. 이동평균선

### 배열
```
정배열: 5 > 20 > 60 > 120  (상승 추세)
역배열: 5 < 20 < 60 < 120  (하락 추세)
```
| 이평선 | 별칭 | 의미 |
|--------|------|------|
| 5일 | 심리선 | 단기 방향 |
| 20일 | **생명선** | 스윙 기준. 이탈 시 단기 추세 훼손 |
| 60일 | **수급선** | 중기 추세 |
| 120일 | 경기선 | 장기 추세 |

### 정배열/역배열의 심리 구조
- **정배열** = 모든 기간대 참여자가 수익 중 → 매물 압력 최소 → 하락 시마다 저가매수 유입
  → **눌림목 매매는 정배열 종목에서만 한다. 이게 전제조건이다.**
- **역배열** = 모든 참여자가 손실 → 반등마다 본전 매물 → **역배열 종목의 반등은 눌림목이 아니라 데드캣 바운스**
- **수렴 구간** = 이평선이 한 점에 모임. 방향성 없음. 볼린저 스퀴즈와 동일 — **돌파 대기 구간이지 진입 구간이 아니다**

### 골든크로스/데드크로스의 진실 ⚠️
1. **본질적으로 후행 지표.** 5×20 골든크로스 발생 시점엔 이미 저점 대비 **10~20% 상승한 뒤**. 진입가가 항상 불리
2. **횡보장에서 whipsaw 연쇄.** 골든→데드→골든이 반복돼 수수료와 손절만 누적. **이평 교차 전략의 손실은 거의 전부 이 구간에서 발생**
3. **명확한 추세장에서만 유효.** 백테스트 일관된 결론: 장기 상승장에선 유효, **횡보장에선 buy&hold 대비 열위**
4. **작전 종목에선 조작 대상.** 유동성 낮은 코스닥은 세력이 의도적으로 골든크로스 모양을 만들어 개인 매수 유도 가능

**개선 규칙 (쓰려면)**
- **거래량 필터**: 크로스일 VR ≥ 1.5. 거래량 없는 크로스 무시
- **추세 필터**: 주가가 200일선(or 120일선) 위일 때만 채택 → whipsaw 대폭 감소
- **이격 필터**: 붙어서 스치는 크로스는 노이즈

> ★ **눌림목 트레이더의 실용적 결론**:
> **골든크로스를 진입 신호로 쓰지 말고 스크리닝 필터로만 쓴다. 진입은 골든크로스 이후 첫 눌림에서.**
> → 후행성을 회피하면서 추세 확인 효과만 취한다.
>
> 📌 미너비니 Trend Template도 이평선 **배열**을 쓰지 크로스 시점을 쓰지 않는다.

### 그랜빌의 8법칙 — 이평선 매매의 원형
매수 4: ①이평선 하락 후 횡보/상승 전환 시 주가 상향돌파 **②이평선 상승 중 주가 일시 하회 후 회복** **③주가가 이평선 위에서 하락하다 지지받고 반등** ④과대이격 후 반등
> **②③이 정확히 눌림목 매매다.** ①은 추세 전환, ④는 기술적 반등(리스크 높음).

### 이격도
`이격도 = 주가 / 이평선 × 100` — 20일선 110% 이상 = 과열, 눌림 대기

## 4. 매물대 (Volume Profile) ★

가격대별 누적 거래량 분포. **시간축이 아닌 가격축 기준.**

### 형성 원인 (심리)
- 하락 후 재접근 → 그때 물린 사람들의 **본전 매도** → **저항**
- 상승 후 재접근 → 그때 못 산 사람들의 **재매수** → **지지**
- ★ **돌파된 저항은 지지가 된다 (Role Reversal).** 저항 위에서 산 사람은 수익 중이라 안 판다.

### 핵심 구성요소
| 요소 | 정의 | 의미 |
|------|------|------|
| **POC** | 거래량 최다 단일 가격 | **최강 지지/저항. 가격의 자석** |
| **VA** | 전체 거래량 **70%** 발생 구간 | 공정가치 영역 |
| VAH / VAL | VA 상단/하단 | 박스 상단/하단 |
| **HVN** | 거래량 밀집 | **가격이 정체한다. 두꺼운 벽** |
| **LVN** | 거래량 희박 | **가격이 빠르게 통과한다. 진공** |

### ★ 실전 활용 5원칙
1. **LVN = 급등/급락 구간.** 진입하면 다음 HVN까지 저항 없이 이동
   → LVN 하단 매수 + 다음 HVN 상단 목표 = 손익비 우수
   → 🚨 **손절선을 LVN 안에 두면 순식간에 관통당한다. 손절은 반드시 HVN 아래.**
2. **주가 위 두꺼운 매물대 = 상승 저항.** 바로 위 5%에 거대 HVN이 있으면 손익비가 안 나옴 → **진입 스킵**
3. **주가 아래 두꺼운 매물대 = 지지 1순위.** ⭐ **이평선보다 매물대 HVN이 우선한다** (이평선은 계산값, 매물대는 실제 거래 흔적)
4. **매물대 소멸**: 큰 매물대가 대량거래로 돌파되면 지지로 역전 → **회전율이 높아야 매물대가 소화된다**
5. **기간 선택**: VPVR(전체)=중장기 / FRVP(고정구간)=특정 파동 / SVP(세션)=당일 단타

### 신고가의 위력
52주 신고가 = **위에 매물대가 아예 없다.** 미너비니가 신고가 근처를 선호하는 구조적 이유.

### ★ 컨플루언스 최상급 셋업
```
20일선 ∩ 전고점(돌파된 저항) ∩ 피보 38.2% ∩ 매물대 HVN 상단 ∩ Anchored VWAP
+ 거래량 감소 + 아래꼬리 양봉
```
> 이 정도 겹치는 자리가 눌림목 매매의 최상급 셋업.
> **자주 안 나오는 게 정상이며, 안 나올 때 안 하는 것이 이 전략의 핵심 실력이다.**
