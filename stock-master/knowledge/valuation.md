# 밸류에이션 — FPER 중심

---

## 1. FPER (Forward PER, 선행 PER)

### 정의
```
FPER = 현재 주가 / 향후 12개월 예상 EPS (컨센서스)
```
후행 PER은 **이미 확정된 과거 실적** 기준 → 주가가 미래 성장을 선반영하면
항상 "비싸 보이는" 함정. FPER은 이 후행성을 제거한다.

### 종류
| 지표 | 분모 | 언제 쓰나 |
|------|------|-----------|
| Trailing PER | 최근 4개 분기 실적 EPS | 실적 안정 기업 |
| 당해년도 예상 PER | 올해 컨센서스 EPS | 연초 |
| 차년도 예상 PER | 내년 컨센서스 EPS | 연말로 갈수록 |
| **12M Forward PER** | 향후 12개월 롤링 EPS | **전 기간 일관 비교 — 기본값** |

---

## 2. FPER 실전 활용 4가지

### ① 자기 역사와 비교 (가장 중요)
절대 수치보다 **밴드 내 위치**가 핵심.
```
종목 A: 과거 5년 FPER 밴드 8~15배, 현재 9배 → 하단 (저평가 구간)
종목 B: 과거 5년 FPER 밴드 8~15배, 현재 14배 → 상단 (부담)
```
**KOSPI 지수 자체도 동일**: 과거 FPER 밴드 대비 현재 위치로 시장 과열/침체 판단.

### ② EPS 추정치 **방향**이 절대 레벨보다 중요
```
FPER 10배인데 EPS 추정치 하향 중  → 함정 (분모가 줄면 PER은 다시 오른다)
FPER 20배인데 EPS 추정치 상향 중  → 정당화 가능
```
> 📌 **미너비니 연결**: SEPA의 "Fundamentals = 이익 가속"이 바로 이것.
> **EPS 추정치 상향 리비전(revision)** 이 추세추종의 펀더멘털 근거.

### ③ PEG로 성장 감안
```
PEG = FPER / EPS 성장률(%)
PEG < 1  → 성장 대비 저평가
PEG > 2  → 부담
```

### ④ 섹터 내 상대비교
반도체 15배 vs 유틸리티 15배는 전혀 다른 의미. **같은 업종 내에서만** 비교.

## 3. FPER의 함정 ⚠️

| 함정 | 내용 |
|------|------|
| **컨센서스 낙관 편향** | 애널리스트 추정치는 구조적으로 낙관적. 실제보다 높게 시작해 하향 조정되는 패턴 |
| **경기민감주 역설** | 시클리컬은 **호황기 PER 최저(고점), 불황기 PER 최고(바닥)**. 저PER = 매수 신호가 아니라 **고점 신호** |
| **적자기업 무의미** | EPS ≤ 0이면 PER 계산 불가 → PSR, EV/Sales 사용 |
| **일회성 손익 왜곡** | 자산매각 등으로 EPS 튀면 왜곡 → 영업이익 기반 지표 병행 |
| **추정치 커버리지 부족** | 소형주는 애널리스트 2~3명 → 신뢰도 낮음 |

> ⚠️ **반도체(한국 핵심)에 특히 주의**: 삼성전자·SK하이닉스는 전형적 시클리컬.
> PER이 낮을 때가 사이클 고점일 수 있다. **PBR + 업황(DRAM 가격)** 병행 필수.

---

## 4. 보조 지표

| 지표 | 공식 | 용도 |
|------|------|------|
| **PBR** | 주가 / 주당순자산 | 자산주·시클리컬 바닥 판단. 1배 = 청산가치 |
| **EV/EBITDA** | 기업가치 / 영업현금흐름 | 부채구조 다른 기업 비교. 감가상각 큰 산업 |
| **PSR** | 시총 / 매출 | 적자 성장기업 |
| **ROE** | 순이익 / 자기자본 | 질(quality). **PBR = PER × ROE** |
| **배당수익률** | 주당배당 / 주가 | 금리와 비교 |

### 듀퐁 분해
```
ROE = 순이익률 × 자산회전율 × 재무레버리지
```
ROE가 **레버리지로만** 높으면 위험. 순이익률·회전율에서 나와야 진짜.

---

## 5. 추세추종에서 밸류에이션의 위치

미너비니 관점에서 **밸류에이션은 진입 근거가 아니다.**

```
❌ "FPER 8배라 싸니까 산다"           → 하락 추세면 후보 아님
✅ "추세·VCP 확인됨 + FPER도 밴드 하단" → 진입 강화 근거
✅ "FPER 밴드 상단 + 급등"            → 익절 시점 고려 근거
```

**역할 정리**
| 용도 | 유효성 |
|------|--------|
| 진입 트리거 | ❌ (추세가 트리거) |
| 진입 **보강** 근거 | ⭕ |
| 목표가 설정 | ⭕ (밴드 상단 = 1차 목표) |
| 리스크 인식 | ⭕ (밴드 상단 + 추정 하향 = 위험) |
