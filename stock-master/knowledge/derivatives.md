# 선물·옵션 — 베이시스, 괴리율, 프로그램매매, 그릭스

---

## 1. 선물 이론가와 베이시스

### 이론가격 공식
```
선물 이론가 = 현물지수 × [1 + (r - d) × (T/365)]

r = 무위험이자율(CD금리 등)
d = 배당수익률
T = 잔존일수
```
간이형: `이론가 = 현물 + 보유비용(이자) - 배당`

### 베이시스
```
시장 베이시스 = 선물 시장가 - 현물지수
이론 베이시스 = 선물 이론가 - 현물지수
괴리(율)     = 시장 베이시스 - 이론 베이시스
```

| 상태 | 명칭 | 의미 |
|------|------|------|
| 선물 > 현물 | **콘탱고(Contango)** | 정상. 이론 베이시스는 통상 (+) |
| 선물 < 현물 | **백워데이션(Backwardation)** | 비정상. 강한 매도 압력·비관 |

> ⚠️ 이론 베이시스는 만기가 가까울수록 **0으로 수렴**한다 (보유비용 소멸).
> 만기 직전 베이시스가 크면 그건 이론이 아니라 수급 왜곡이다.

## 2. 차익거래(Arbitrage)와 프로그램매매

### 차익거래 방향
| 조건 | 선물 상태 | 거래 | 프로그램 |
|------|-----------|------|----------|
| 시장가 > 이론가 (괴리 +) | 고평가 | 선물 매도 + 현물 매수 | **매수차익** 유입 |
| 시장가 < 이론가 (괴리 −) | 저평가 | 선물 매수 + 현물 매도 | **매도차익** 출회 |

### 프로그램매매 정의 (한국)
- KOSPI200 바스켓 ↔ 선물/옵션 연계 **지수차익거래 전부**
- 동일인이 지수구성종목 **15종목 이상** 동시 거래

### 실전 해석 — 왜 봐야 하나
- **베이시스 개선(+ 확대)** → 매수차익 유입 여력 → 현물 수급 우호
- **베이시스 악화(− 전환)** → 매도차익 출회 → **현물 지수 하방 압력**
- 외국인 선물 순매수 + 베이시스 개선 = 지수 상승 시그널로 자주 작동
- **매수차익 잔고 누적**이 크면 = 언젠가 청산될 **잠재 매도 물량**

> 💡 미노 스타일 활용: 개별 종목 눌림목 타점에서 **지수 베이시스가 악화 중이면**
> 프로그램 매도로 개별주도 같이 밀릴 수 있다 → 진입 타이밍 반박자 늦추는 근거.

## 3. 옵션 그릭스

| 그릭 | 정의 | 실전 의미 |
|------|------|-----------|
| **델타(Δ)** | 기초자산 1p 변화 시 옵션가 변화 | 방향 노출. ATM≈0.5. 헤지비율 |
| **감마(Γ)** | 델타의 변화율 | ATM·만기 임박 시 폭증. **급등락의 증폭기** |
| **세타(Θ)** | 시간가치 감소 | 매수자의 적. 만기 임박 시 가속 소멸 |
| **베가(ν)** | IV 1%p 변화 시 옵션가 변화 | 변동성 노출. 잔존기간 길수록 큼 |

### 그릭스 심화

**델타의 3가지 용법**
1. 헤지비율 (델타 0.5 콜 2계약 = 기초자산 1단위 노출)
2. **만기 시 ITM 종료 확률의 근사치** (델타 0.30 ≈ 내가격 확률 30%)
3. 포지션 방향성 익스포저 합산

> 매도 전략에서 "델타 16~30" 행사가를 고르는 관행 = 델타를 확률 프록시로 쓰는 것 (16델타 ≈ 1표준편차 밖)

**★ 감마-세타 트레이드오프 = 옵션의 본질**
```
롱감마 = 숏세타   (움직임을 사는 대신 매일 시간값 지불)
숏감마 = 롱세타   (매일 시간값 벌지만 큰 움직임에 손실 가속)
```
**공짜 점심은 없다.**
- 롱감마: 오르면 델타 커지고 내리면 작아짐 → 유리한 방향으로 저절로 변함
- 숏감마: 반대. 손실이 가속

**세타는 선형이 아니다** — 잔존만기의 **제곱근에 비례해 가속**. 만기 30일 이내부터 급격히 붕괴, ATM에서 가장 심함.

**만기별 지배 그릭**
| 구간 | 지배 |
|------|------|
| 원월물 | **베가** 지배 |
| 근월물·만기주간 | **감마·세타** 지배 (베가는 0 수렴) |

### 감마 스퀴즈
**피드백 루프**
```
1. 특정 행사가 콜 대량 매수
2. 딜러(MM)는 반대편 콜 매도 → 숏감마
3. 델타중립 위해 기초자산 매수 헤지
4. 주가 상승 → 콜 델타 증가(감마) → 딜러 추가 매수
5. 추가 매수가 주가를 더 올림 → 3~5 반복 (자기강화)
```

**성립 3요건**: ① 근접 행사가 콜 미결제약정 집중 ② **음(−)의 딜러 감마(GEX)** ③ 촉매
+ **얕은 유동성**(유통주식 적음, 대차 부족)이면 폭발력 배가

### ★ GEX (딜러 감마 익스포저) 레짐 — 변동성 예측 도구
| GEX | 딜러 행동 | 시장 효과 |
|-----|-----------|-----------|
| **양(+)** (딜러 롱감마) | 오르면 팔고 내리면 삼 | **변동성 억제, 가격 고정(pinning)** |
| **음(−)** (딜러 숏감마) | 오르면 사고 내리면 팜 | **변동성 증폭**, 방향 무관 추세 가속 |

GEX가 0을 넘나드는 **감마 플립 레벨**이 구조적 변곡점.

> ⚠️ 감마 스퀴즈 ≠ 숏스퀴즈. 숏스퀴즈는 공매도 환매수가 동력, 감마 스퀴즈는 **딜러 델타헤지**가 동력. 실전에선 동시 발생 잦음.

### 변동성 — IV vs HV

```
IV(내재변동성) = 옵션 시장가에서 역산한 미래 기대 변동성 (전망, 리스크프리미엄 포함)
HV(역사변동성) = 과거 실제 수익률 표준편차 (사후, 실측)
```

> **구조적 사실: IV > HV가 정상이다.**
> 그 차이 = **변동성 리스크 프리미엄(VRP)**. 옵션 매도자가 장기 우위를 갖는 근거.

- **IV < HV** → 옵션이 상대적으로 쌈 → 매수 우호
- **IV >> HV** → 프리미엄 과대 → 매도 우호 (단, **큰 움직임 예고**일 수도 → 실적/M&A 확인 필수)

### IV Rank vs IV Percentile
```
IV Rank       = (현재IV − 52주최저) / (52주최고 − 52주최저) × 100
IV Percentile = (252거래일 중 IV가 현재보다 낮았던 일수) / 252 × 100
```

| | IV Rank | IV Percentile |
|---|---------|---------------|
| 사용 데이터 | **최고·최저 2개 값만** | **분포 전체** |
| 이상치 | **단발 스파이크에 크게 왜곡** | 강건 |
| 신뢰도 | 낮음 | **일반적으로 더 신뢰** |

⚠️ 한 번의 폭락으로 최고IV가 90까지 튀면 **이후 1년 내내 IV Rank가 낮게 나온다.**
→ **둘을 함께 보는 것이 정석.** 둘 다 높으면 강한 확증.

| 구간 | 해석 | 전략 편향 |
|------|------|-----------|
| **> 70** | 프리미엄 매우 비쌈 | 적극 매도 (사이즈↑) |
| **> 50** | 높음 | 매도 우호 |
| 30~50 | 중립 | 방향성·캘린더 |
| **< 30** | 쌈 | 매수 우호 (롱옵션, 데빗스프레드) |

**IV Crush**: 이벤트 직후 IV 급락. **방향을 맞춰도 손실** — 초보 최대 함정.

### VKOSPI
KOSPI200 옵션 기반 **향후 30일** 기대변동성 연율화. KRX가 **2009.4.13 아시아 최초** 개발, **30초 단위** 산출.
산출은 VIX와 동일한 **공정분산스왑** 방식 (ATM + OTM 전체 스트립 가중합, 특정 모델 비의존).

| VKOSPI | 상태 |
|--------|------|
| ~20 초반 | 안정 |
| 20 후반 | 경계 |
| **30 이상** | **고변동성 = 공포** |
| 40+ | 패닉/시스템 리스크 |
| **15 이하** | 과도한 안일 (역발상 경계) |

**해석 3원리**
1. **비대칭성** — 하락 시 급등, 상승 시 완만 하락. 그래서 '공포지수'. 상승장에서 VKOSPI가 안 오르면 = 심리 견고
2. **평균회귀** — 변동성은 추세보다 평균회귀 성향. 스파이크 후 정상화 베팅이 통계적 우위
3. **역발상** — 극단 고점은 종종 시장 바닥과 일치

**VIX와의 차이**
| | VIX | VKOSPI |
|---|-----|--------|
| 기초 | S&P500 | KOSPI200 |
| 파생상품 | 선물·옵션·ETP 대규모 | **직접 헤지수단 사실상 부재** |
| 수준 | — | **통상 VIX보다 높게 형성** (EM 리스크프리미엄) |

- ⚠️ 한국은 미국에 동조 → **VIX 급등이 시차를 두고 VKOSPI를 끌어올림**. VIX를 선행지표로.
- VKOSPI는 직접 매매 불가 → 변동성 뷰는 KOSPI200 옵션으로 간접 표현

## 4. 만기 이벤트

| 이벤트 | 시기 |
|--------|------|
| 일반 옵션 만기 | 매월 **둘째 목요일** |
| **위클리 옵션** | **매주 목요일** (상장돼 있음) |
| 선물 만기 | 3·6·9·12월 둘째 목요일 |
| **네 마녀의 날** | 3·6·9·12월 둘째 목요일 (한국) / 셋째 금요일 (미국) |

### 변동성의 실제 동인 = 프로그램 청산
```
1. 만기 1~2주 전 외국인·기관이 베이시스 노려 차익 포지션 구축
2. 만기일 동시호가에 일시 청산
3. KOSPI200 편입비중 큰 대형주 직격 (바스켓 단위 실행)
```
**관전 포인트 = 베이시스 방향.** 백워데이션이면 매수차익잔고 청산 = **매도 압력**.

### ★ 통념 반박 — 실증 데이터 (2021~2025, 5년)
| 항목 | 네 마녀의 날 | 일반 거래일 |
|------|-------------|------------|
| 코스피 평균 등락 | **+0.61%** (상승 편향) | — |
| **표준편차** | **1.03%** | **1.28%** |
- 20번 중 **13번 상승**

> 🚨 **"네 마녀의 날 = 폭락"은 미신에 가깝다.**
> 일간 종가 기준으로는 오히려 변동성이 **낮았다**.
> 단, **장중 종가 무렵(동시호가) 급변동은 실재**한다.
> 실제 리스크 = 방향이 아니라 **만기 직전 며칠간 수급 왜곡 + 만기 익일 되돌림**.

### 만기 주간 옵션 특성
- 감마 폭증 + 세타 폭증 → 매도자는 프리미엄이 빨리 녹지만 **사고 한 방에 몰살** 가능
- **핀 리스크(pinning)**: 미결제 많은 행사가로 주가가 끌려가 만기 (딜러 롱감마 효과)
- 베가 0 수렴 → IV 변화 무의미

## 5. 옵션 전략

### ★ 전략 선택 매트릭스 — IV가 결정한다
| | **IV 낮음 (IVR<30)** | **IV 높음 (IVR>50)** |
|---|---|---|
| **강세** | 콜 매수, 불 콜스프레드(데빗) | 풋 매도, 불 풋스프레드(크레딧), **커버드콜** |
| **약세** | 풋 매수, 베어 풋스프레드(데빗) | 베어 콜스프레드(크레딧) |
| **중립/횡보** | 캘린더 스프레드 | **아이언 콘도르**, 스트랭글 매도 |
| **큰 변동 예상** | **스트래들/스트랭글 매수** | ⚠️ 진입 회피 (IV 크러시) |

> 💡 **핵심**: 같은 강세 뷰라도 IV가 낮으면 **데빗**, 높으면 **크레딧** 스프레드.
> 방향 뷰만 보고 전략을 고르면 절반만 맞춘 것.

### 매도(프리미엄 수취) — IV 높을 때

**① 커버드콜** = 현물 + 콜매도
- 중립~완만상승, 보합 횡보장 최적. 숏베가·롱세타·숏감마
- 수익 상단 = 행사가 + 프리미엄으로 **캡**. 하방보호는 프리미엄만큼만
- 목표가 도달 시 매도할 생각이던 종목에 최적
- ⚠️ 급등장 상승분 통째로 놓침. **하락장 방어력 거의 없음**

**② 아이언 콘도르** = OTM 풋스프레드 매도 + OTM 콜스프레드 매도
- 횡보 + 높은 IV → IV 하락 예상. **손익 양쪽 모두 제한**
- 최대이익 = 순수취 프리미엄, 최대손실 = 스프레드폭 − 프리미엄
- 증거금 효율 좋음. **필수조건: IVR > 50 (이상적 >70)**. 낮은 IV에서 하면 리스크 대비 열악

**③ 스트랭글 매도** = OTM 콜매도 + OTM 풋매도
- 콘도르의 무한리스크 버전. 프리미엄 크지만 **손실 무한** → 증거금 부담. 테일리스크 치명적

### 매수(프리미엄 지불) — IV 낮을 때

**④ 프로텍티브 풋** = 현물 + 풋매수
- 강세 유지하되 하방 보험 (실적, 매크로 이벤트). 롱베가·숏세타·롱감마
- 하방 손실 = 행사가까지 제한, 상방 무한
- ⚠️ **보험료가 비싸다.** 상시 운용하면 세타 출혈로 장기수익 갉아먹음
- **IV 낮을 때 미리 사두는 게 정석. VKOSPI 30 넘고 사면 이미 늦음**
- 커버드콜과 결합 = **칼라(Collar)** — 콜매도로 풋비용 상쇄

**⑤ 스트래들 매수** = 동일 행사가 ATM 콜+풋
- 방향 모르나 큰 움직임 확실 (실적, 임상, 정책)
- 손익분기 = 행사가 ± 총프리미엄
- ⚠️ **필수: IV 낮을 때 진입.** 이벤트 직전엔 IV가 이미 부풀어 → 방향 맞아도 **IV 크러시로 손실**. 초보 최다 함정
- 세타 출혈 크므로 **빨리 움직여야** 함

**⑥ 스트랭글 매수** = OTM 콜+풋 (다른 행사가)
- 스트래들보다 저렴하나 **더 큰 움직임 필요**. 자본효율 좋고 승률 낮음

### 스프레드
- **불 콜(데빗)**: 낮은행사가 콜매수 + 높은행사가 콜매도 — 완만상승, IV 낮을 때
- **불 풋(크레딧)**: 높은행사가 풋매도 + 낮은행사가 풋매수 — 같은 상승뷰인데 **IV 높을 때**
- **베어 풋(데빗)** / **베어 콜(크레딧)** — 하락 뷰, 동일 논리

### 풋콜 레이시오 (PCR)
```
PCR = 풋 거래량(또는 미결제) / 콜 거래량(또는 미결제)
```
- **거래량 기준** = 단기 심리, 노이즈 큼 / **미결제 기준** = 포지션 축적, 안정적

| PCR | 심리 | 역발상 |
|-----|------|--------|
| **< 0.5** | 극단 낙관 | **경계 — 조정 위험** |
| 0.5~0.7 | 강세 낙관 | — |
| **0.7~1.0** | **중립 (정상)** | — |
| > 1.0 | 약세 | — |
| **> 1.5** | 극단 공포 | **반등 가능 — 매수 신호** |

⚠️ **실전 주의**
- **절대 임계값을 물리상수처럼 쓰지 마라.** 자산마다 기준 PCR 수준이 다름 → **자체 이동평균 대비 편차**로 볼 것
- **DTE 7일 초과** 옵션으로 계산하면 노이즈 감소
- 지수 PCR은 구조적으로 1보다 높다 (기관 **포트폴리오 헤지용 풋 상시 매수**). 개별주와 같은 잣대 금지
- 단독 사용 금지 — VKOSPI/VIX·수급·추세 교차확인
