# /복기 — 매매 복기

> `stock-master` 브랜치 전용.

## 목적
**결과가 아니라 프로세스를 평가한다.**
- 돈 벌었어도 규칙 어겼으면 → **나쁜 매매** (운으로 산 것)
- 손실 났어도 규칙 지켰으면 → **좋은 매매** (계속해도 되는 것)

## 입력 없으면 물어볼 것
종목 / 진입가·시점 / 진입 근거 / 손절 설정값 / 실제 청산가·시점 / 비중

## 평가 3축

### 축 1 — 진입 근거
- Trend Template 통과 상태에서 샀나?
- VCP 피벗 등 **정의된 타점**이었나, 아니면 충동·FOMO였나?
- 촉매가 있었나?
- ❗ "그냥 올라갈 것 같아서" → 근거 없음으로 기록

### 축 2 — 손절 규율 ★ 가장 중요
- 진입 **전에** 손절가를 정했나?
- 손절폭이 8% 이내였나?
- 실제로 지켰나? **밀었나?**
- ❗ 손절 미루기 = 계좌 파괴 1순위 원인. 발견 시 강하게 지적.

### 축 3 — 포지션 사이징
- 계좌 대비 리스크가 1.25~2.5% 범위였나?
- 확신이 세다고 비중을 키웠나? (= 규칙 위반)
- 물타기 했나? ❗ (= 즉시 교정 대상)

## 출력 포맷

```markdown
## 📝 매매 복기 — [종목] YYYY-MM-DD

### 판정: 🟢좋은매매 / 🟡보통 / 🔴나쁜매매
[결과와 무관하게 프로세스 기준]

| 축 | 평가 | 코멘트 |
|----|------|--------|
| 진입 근거 | ⭕/△/❌ | |
| 손절 규율 | ⭕/△/❌ | |
| 사이징 | ⭕/△/❌ | |

### 잘한 것
### 고칠 것 (우선순위 1개만)
### 다음 매매 체크리스트 1줄
```

## 원칙
- **띄워주지 마라.** 코치의 역할은 위로가 아니라 교정.
- 단, 인신공격 ❌ → 행동에 대한 피드백 ⭕
- 고칠 점은 **한 번에 1개**. 여러 개 지적하면 아무것도 안 고쳐진다.
- 반복 오류는 패턴으로 지적 ("이번이 3번째 손절 미루기").

## 기록
요청 시 `stock-master/journal/YYYY-MM-DD.md`에 저장.
