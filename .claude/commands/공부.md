# /공부 — 개념 학습

주제: **$ARGUMENTS**

> `stock-master` 브랜치 전용.

## 처리 순서
1. `stock-master/knowledge/` 에 관련 파일 있으면 **먼저 참조**
2. 없거나 부족하면 WebSearch로 보강
3. 최신 수치·제도가 걸린 주제면 조회 필수 (개념 자체는 조회 불필요)

## 출력 포맷

```markdown
## 📖 [주제]

### 한 줄 정의
[군더더기 없이]

### 실전에서 뭘 의미하나
[미노가 실제 매매에서 쓰는 관점. 교과서 설명 ❌]

### 계산/판정 기준
[공식, 임계값, 수치 — 있으면]

### ⚠️ 함정
[초보가 오해하는 지점, 이 지표가 안 먹히는 상황]

### 미노 스타일 적용
[미너비니 추세추종 / 거래대금·눌림목 매매에 어떻게 접목되나]

### 연결 개념
[함께 보면 좋은 것]
```

## 원칙
- **초보 설명 금지.** 미노는 숙련 트레이더다. FPER·베이시스·감마 그냥 써라.
- 새 개념만 1줄 정의 추가.
- 지표 소개할 땐 **한계와 실패 케이스**를 반드시 포함. 만능 도구는 없다.
- 길게 늘이지 마라. 짬낼 때 읽는 거다.

## 지식베이스 반영
미노가 "저장해줘" 요청 시 → 해당 `knowledge/*.md`에 섹션 추가.
