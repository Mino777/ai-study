# /토론 — 적대적 강세 vs 약세 토론

대상: **$ARGUMENTS**

> `stock-master` 브랜치 전용.
> 출처: [TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents) (GitHub 트레이딩 부문 1위, 95.7k★)
> 다중 에이전트 LLM 트레이딩 프레임워크의 **구조화된 토론 메커니즘**을 1세션용으로 이식.

## 왜 이게 필요한가
혼자 분석하면 **확증편향**이 반드시 낀다. 미노가 이미 관심 있는 종목이면 더 심하다.
강세/약세를 **명시적으로 분리해서 서로 반박**시키면 한쪽 시각의 사각지대가 드러난다.

## 🚫 최우선 규칙
시세·실적·수급은 **WebSearch로 조회 후** 토론. 양측 모두 **실제 데이터로 논증**해야 한다.
데이터 없이 "느낌"으로 토론하면 이 커맨드는 무의미하다.

---

## 1단계 — 애널리스트 4인 (사실 수집)

각 관점에서 **사실만** 수집. 결론 내지 마라.

| 애널리스트 | 수집 항목 |
|-----------|-----------|
| **펀더멘털** | 매출·영업이익 YoY, EPS 추이, FPER, 부채, ROE |
| **테크니컬** | Trend Template 8조건, 이평 배열, 거래대금, 매물대, VCP 여부 |
| **뉴스/매크로** | 촉매, 업황, 금리·환율 영향, 섹터 사이클 |
| **수급/센티먼트** | 외국인·기관 순매수, 공매도 잔고, 시장 심리 |

## 2단계 — 적대적 토론 (핵심)

### 🐂 강세 애널리스트
**역할**: 이 종목을 **사야 하는 이유**를 최대한 강하게 논증한다.
1. **성장 잠재력** — 시장 확대, 신제품, 점유율
2. **경쟁 우위** — 해자, 기술, 브랜드
3. **긍정 지표** — 재무·차트·수급에서 유리한 데이터
4. **약세 논리 반박** — 약세 측 주장을 **구체적 데이터로** 재반박

### 🐻 약세 애널리스트
**역할**: 이 종목을 **사면 안 되는 이유**를 최대한 강하게 논증한다.
1. **리스크·역풍** — 시장 포화, 재무 불안, 매크로 위협
2. **경쟁 열위** — 포지셔닝 취약, 혁신 둔화, 경쟁자 위협
3. **부정 지표** — 재무·차트·수급에서 불리한 데이터
4. **강세 논리 반박** — 강세 측 주장을 **구체적 데이터로** 재반박

### 토론 규칙
- **대화체로 서로 직접 반박한다.** 사실 나열 금지 — 상대 주장을 지목해서 깨라
- **최소 2라운드.** 1라운드 주장 → 2라운드 상호 반박
- 근거 없는 주장은 상대가 **"데이터 없음"으로 지적**
- 어느 쪽도 봐주지 마라. 미노가 좋아하는 종목이어도 약세 측은 냉정하게

## 3단계 — 트레이더 종합
양측 논거를 저울질. **어느 쪽 논리가 더 데이터에 근거했나?**

## 4단계 — 리스크 매니저
- 이 포지션의 최대 손실 시나리오
- 손절폭이 8% 이내인가
- 시장 국면이 진입 허용 구간인가
- 계좌 리스크 1~2% 기준 적정 수량

## 5단계 — 최종 판정

```markdown
## ⚖️ [종목] 강세 vs 약세 토론

### 📊 사실 (조회 데이터)
[4개 애널리스트 수집 사실 — 출처 명시]

### 🐂 강세 논거
### 🐻 약세 논거
### 🔥 쟁점 (양측 충돌 지점)
| 쟁점 | 강세 주장 | 약세 주장 | 데이터 우위 |
|------|----------|----------|------------|

### ⚖️ 판정
**우세: 강세 / 약세 / 판정불가**
[왜 그런지 2~3줄]

### 🎯 실행 시나리오
| 구분 | 조건 |
|------|------|
| 🟢 진입 | |
| 🔴 손절 | (손절폭 %) |
| 🎯 목표 | |
| ⚠️ 무효화 | [이 조건이면 강세 논리 전체가 깨진다] |

### 🚨 약세 측이 지적한 것 중 미노가 무시하면 안 되는 것 1개
[가장 뼈아픈 반론]
```

## 원칙
- **판정불가도 정당한 결론이다.** 억지로 한쪽 편들지 마라
- 마지막 항목(뼈아픈 반론)을 **절대 생략하지 마라** — 이 커맨드의 존재 이유다
- 매매 권유 ❌ → 조건부 시나리오 ⭕
