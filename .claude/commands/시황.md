# /시황 — 시황 브리핑

> `stock-master` 브랜치 전용. 반드시 **WebSearch로 실제 데이터 조회 후** 작성.

## 🚫 최우선 규칙
**기억 속 숫자를 쓰지 마라.** 모든 수치는 조회한 것만. 못 가져온 항목은 "데이터 없음"으로 표기.

## 조회 (병렬 실행)
1. 코스피/코스닥 지수, 등락률, 거래대금
2. 투자자별 수급 (외국인/기관/개인 순매수)
3. 미국 증시 (S&P500, 나스닥) + 달러인덱스 + 원/달러 + 미국 10년물
4. 주요 뉴스 / 이벤트 (FOMC, 실적, 지표 발표)
5. 섹터별 등락, 거래대금 상위 종목

## 출력 포맷

```markdown
## 📊 시황 브리핑 — YYYY-MM-DD

### 한 줄 요약
[오늘 시장을 한 문장으로]

### 1. 매크로
| 항목 | 수치 | 전일비 | 해석 |
|------|------|--------|------|
| 미 10년물 | | | |
| DXY | | | |
| 원/달러 | | | |
- 금리·달러 방향이 한국 수급에 미치는 경로 1~2줄

### 2. 수급
| 주체 | 코스피 | 코스닥 |
|------|--------|--------|
| 외국인 | | |
| 기관 | | |
| 개인 | | |
- 선물 베이시스 / 프로그램 방향 (확인 가능 시)

### 3. 지수 기술적 위치
- 코스피: 이평선 대비 위치, 정배열 여부, 지지/저항
- 시장 국면: 신규 진입 허용 / 경계 / 현금 (미너비니 Market Timing)

### 4. 섹터 & 주도주
- 강세 섹터 / 약세 섹터
- 거래대금 상위 특징주 + 이유

### 5. 오늘의 관전포인트
- 확인할 것 2~3개
- ⚠️ 리스크 요인
```

## 원칙
- 결론 먼저. 서론 금지.
- 강세 뷰면 약세 시나리오도 반드시 병기.
- 매매 권유 ❌ → 관찰 포인트와 조건 ⭕
- 출처 URL 명시.
