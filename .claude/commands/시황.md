# /시황 — 시황 브리핑

> `stock-master` 브랜치 전용. 반드시 **WebSearch로 실제 데이터 조회 후** 작성.

## 🚨 최우선 규칙 — 최신 데이터만
1. **기억 속 숫자 금지.** 모든 수치는 조회한 것만
2. **검색 결과의 날짜를 확인해라.** 낡은 기사를 오늘 시황으로 쓰는 게 최다 실패 모드
3. **주가·지수·수급은 당일~1영업일만 유효.** 그보다 오래된 건 재조회
4. 표의 모든 숫자에 **기준일 명시**
5. 못 가져온 항목은 **"데이터 없음"** 으로 명시 — 빈칸을 추정으로 채우지 마라
6. `journal/*.md` 의 과거 스냅샷을 **현재값으로 인용 금지**

## 조회 (병렬 실행)
1. 코스피/코스닥 지수, 등락률, 거래대금
2. 투자자별 수급 (외국인/기관/개인 순매수)
3. 미국 증시 (S&P500, 나스닥) + 달러인덱스 + 원/달러 + 미국 10년물
4. 주요 뉴스 / 이벤트 (FOMC, 실적, 지표 발표)
5. 섹터별 등락, 거래대금 상위 종목

## 출력 포맷

```markdown
## 📊 시황 브리핑 — YYYY-MM-DD
> 데이터 기준: [각 항목의 실제 기준일. 항목마다 다르면 다르게 표기]

### 한 줄 요약
[오늘 시장을 한 문장으로]

### 1. 매크로
| 항목 | 수치 | 전일비 | 해석 |
|------|------|--------|------|
| 미 10년물 | | | |
| DXY | | | |
| 원/달러 | | | |
- 금리·달러 방향이 한국 수급에 미치는 경로 1~2줄

### 2. 수급
| 주체 | 코스피 | 코스닥 |
|------|--------|--------|
| 외국인 | | |
| 기관 | | |
| 개인 | | |
- 선물 베이시스 / 프로그램 방향 (확인 가능 시)

### 3. 지수 기술적 위치
- 코스피: 이평선 대비 위치, 정배열 여부, 지지/저항
- 시장 국면: 신규 진입 허용 / 경계 / 현금 (미너비니 Market Timing)

### 4. 섹터 & 주도주
- 강세 섹터 / 약세 섹터
- 거래대금 상위 특징주 + 이유

### 5. 오늘의 관전포인트
- 확인할 것 2~3개
- ⚠️ 리스크 요인
```

## 원칙

- 강세 뷰면 약세 시나리오도 반드시 병기.
- 매매 권유 ❌ → 관찰 포인트와 조건 ⭕
