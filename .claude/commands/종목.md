# /종목 — 종목 분석

분석 대상: **$ARGUMENTS**

> `stock-master` 브랜치 전용. **WebSearch로 실제 데이터 조회 필수.**

## 🚨 최우선 규칙 — 최신 데이터만
1. 현재가·실적·수급을 **기억으로 답하지 마라.** 반드시 조회
2. **검색 결과의 날짜 확인** — 낡은 기사의 주가를 현재가로 쓰면 Trend Template 판정이 **통째로 틀린다**
3. 주가·이평선·수급은 **당일~1영업일** 데이터만 사용
4. 모든 수치에 **기준일 명시**
5. 조회 실패 항목은 **"확인 불가"** 로 명시. 그 항목 없이 가능한 범위만 답한다
   → 8개 조건 중 확인 안 되는 게 있으면 **"N/8 판정 불가"** 라고 하지, 추측으로 채우지 마라

## 조회 항목
1. 현재가, 등락률, 거래량/거래대금
2. 52주 최고/최저, 이평선(20/60/120일) 위치
3. 실적 — 최근 분기 매출·영업이익 YoY, EPS 추이
4. 밸류에이션 — FPER, PER, PBR + 업종 평균
5. 수급 — 외국인/기관 최근 순매수 추이
6. 최근 뉴스·촉매

## ⭐ 사내망일 때 (금융사이트 차단 — 2026-08-06 실측)
당일 시세를 못 가져오면 **추측하지 말고 미노에게 요청**한다. HTS에서 바로 보인다:

```
종목명 / 현재가 / 등락률
거래대금
52주 최고 · 최저
20일선 · 60일선 · 120일선
(있으면) 외국인·기관 순매수, PER/PBR
```
> 이 6줄만 주면 **Trend Template 8조건 + 손익비 + 사이징**까지 전부 판정 가능하다.
> 실적·촉매·업종비교는 WebSearch로 보완 (며칠 늦어도 펀더멘털은 덜 민감).

## 출력 포맷

```markdown
## 🔍 [종목명] 분석 — YYYY-MM-DD

### 결론
[3줄 이내. 관심/관망/회피 + 핵심 이유]

### 1. 미너비니 Trend Template
| # | 조건 | 판정 |
|---|------|------|
| 1 | 현재가 > 150일선, 200일선 | ⭕/❌ |
| 2 | 150일선 > 200일선 | |
| 3 | 200일선 상승 중 | |
| 4 | 50일선 > 150·200일선 | |
| 5 | 현재가 > 50일선 | |
| 6 | 52주 저점 대비 +30% 이상 | |
| 7 | 52주 고점 대비 -25% 이내 | |
| 8 | 상대강도 상위 (코스피 대비) | |

**통과: N/8** → [8/8 아니면 왜 탈락인지 명시]

### 2. 차트 구조
- 추세 국면 / 정배열 여부
- VCP 수축 진행 중인가? (조정폭 축소 + 거래량 감소)
- 눌림목이면 지지선 어디, 붕괴 기준 어디
- 매물대 / 전고점

### 3. 펀더멘털
- 실적 가속 여부 (분기 YoY 방향)
- EPS 추정치 리비전 방향 ← **중요**
- FPER 및 자기 밴드 내 위치
- 촉매

### 4. 수급
- 외국인/기관 방향

### 5. 시나리오
| 구분 | 조건 |
|------|------|
| 🟢 진입 | [구체적 가격/조건] |
| 🔴 손절 | [무효화 지점, 손절폭 %] |
| 🎯 목표 | [1차/2차] |
| ⚠️ 리스크 | [반대 시나리오] |

**손절폭이 8% 초과면 → 진입 부적합 자리라고 명시할 것**
```

## 원칙
- Trend Template 실패 조건을 **숨기지 마라**. 미노가 좋아하는 종목이어도 냉정하게.
- 매수 권유 ❌ → 조건부 시나리오 ⭕
- 출처 명시.
