# /종목 — 종목 분석

분석 대상: **$ARGUMENTS**

> `stock-master` 브랜치 전용. **WebSearch로 실제 데이터 조회 필수.**

## 🚫 최우선 규칙
현재가·실적·수급을 **기억으로 답하지 마라.** 반드시 조회.
조회 실패 항목은 "확인 불가"로 명시하고, 그 항목 없이 분석 가능한 범위만 답한다.

## 조회 항목
1. 현재가, 등락률, 거래량/거래대금
2. 52주 최고/최저, 이평선(20/60/120일) 위치
3. 실적 — 최근 분기 매출·영업이익 YoY, EPS 추이
4. 밸류에이션 — FPER, PER, PBR + 업종 평균
5. 수급 — 외국인/기관 최근 순매수 추이
6. 최근 뉴스·촉매

## 출력 포맷

```markdown
## 🔍 [종목명] 분석 — YYYY-MM-DD

### 결론
[3줄 이내. 관심/관망/회피 + 핵심 이유]

### 1. 미너비니 Trend Template
| # | 조건 | 판정 |
|---|------|------|
| 1 | 현재가 > 150일선, 200일선 | ⭕/❌ |
| 2 | 150일선 > 200일선 | |
| 3 | 200일선 상승 중 | |
| 4 | 50일선 > 150·200일선 | |
| 5 | 현재가 > 50일선 | |
| 6 | 52주 저점 대비 +30% 이상 | |
| 7 | 52주 고점 대비 -25% 이내 | |
| 8 | 상대강도 상위 (코스피 대비) | |

**통과: N/8** → [8/8 아니면 왜 탈락인지 명시]

### 2. 차트 구조
- 추세 국면 / 정배열 여부
- VCP 수축 진행 중인가? (조정폭 축소 + 거래량 감소)
- 눌림목이면 지지선 어디, 붕괴 기준 어디
- 매물대 / 전고점

### 3. 펀더멘털
- 실적 가속 여부 (분기 YoY 방향)
- EPS 추정치 리비전 방향 ← **중요**
- FPER 및 자기 밴드 내 위치
- 촉매

### 4. 수급
- 외국인/기관 방향

### 5. 시나리오
| 구분 | 조건 |
|------|------|
| 🟢 진입 | [구체적 가격/조건] |
| 🔴 손절 | [무효화 지점, 손절폭 %] |
| 🎯 목표 | [1차/2차] |
| ⚠️ 리스크 | [반대 시나리오] |

**손절폭이 8% 초과면 → 진입 부적합 자리라고 명시할 것**
```

## 원칙
- Trend Template 실패 조건을 **숨기지 마라**. 미노가 좋아하는 종목이어도 냉정하게.
- 매수 권유 ❌ → 조건부 시나리오 ⭕
- 출처 명시.
